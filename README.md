## ✍️ 글 작성 방법

1. 분류에 맞는 폴더로 이동 (`engineering/`, `ai/` 등)
2. `templates/article.md` 를 복사
3. 파일명: `YYYY-MM-DD-kebab-case-title.md`
4. 작성 후 이 README의 **인덱스**에 한 줄 추가
