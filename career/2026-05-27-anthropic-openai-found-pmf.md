## 핵심 포인트

- **엔터프라이즈 PMF 발견 신호** — *2025-11 코딩 에이전트 실용화 + 2026-04 엔터프라이즈 가격 정상화*가 *PMF 발견 시점*. **[[2026-05-19-simon-willison-six-months-of-llm]] *Simon 6개월 시간 핀의 후속 자산*** — *문화 채널 동일 인물 연속 자산*.
- **헤비 유저 *월 $200 → API $2180/M 사용*** — *11배 가치*. **[[2026-05-26-dont-subscribe-too-lightly]] *구독 비대칭의 *공급자 측 관점***. 어제 박은 *$90 → $1000~4000 = 44배 비대칭*과 *수치 일치 (헤비 유저 11배·평균 사용자 44배 격차)*.
- **2026-04 엔터프라이즈 가격 정상화** — *Anthropic·OpenAI가 공개 API 가격에 맞춤*. **[[2026-05-18-ai-subscription-pricing-truth]] *State of Brand 보조금 종료* 정확한 시점 도착 + *더 비싼 프런티어 모델 동시 출시*는 *수익화 전환 명시 신호*.
- **채용 확대 *엔터프라이즈 영업 비중***: OpenAI 32.6%·Anthropic 26.9%. **[[2026-05-26-uber-coo-ai-token-spending-hard-to-justify]]·[[2026-05-24-microsoft-ai-more-expensive-than-employees]] *기업 측 비용 증가의 *공급자 측 영업 적극화 신호*** — 비용 폭증이 *공급자 측 영업 가속 + 수익화 압박 동시 진행*.
- **ChatGPT *유료 5.6%* 한계 극복 신호** — 9억 주활성 중 *유료 전환 어려움이 *기업 수익화로 우회**. *소비자 PMF의 *기업 PMF로 변형*.
- ***기업 월 $200 지출 → $1조 인프라 투자 정당화*** — **[[2026-05-21-is-ai-profitable]] *산업 누적 손실 $780B* 회수 시나리오 도착**. *기업 시장 = 적자 회수 경로*로 해석.
- **Uber·MS 논란 *재해석*** — *AI 실패가 아니라 *가격 적정성 신호*. **[[2026-05-26-uber-coo-ai-token-spending-hard-to-justify]]·[[2026-05-24-microsoft-ai-more-expensive-than-employees]]의 *정반대 해석 자산 도착*** — *같은 데이터에 *axelk 측 (지속 불가능)* vs *Lasn 측 (적정성 신호)* 분기*.
- **SpaceX 월 $12.5억 계약** — Anthropic이 *추론 인프라 대폭 확충*. **[[2026-05-24-memory-two-thirds-ai-chip-bom]] *HBM 63% + Microsoft $190B CapEx + SpaceX $12.5억* = AI 산업 인프라 투자 3 측면 도착***.
