# Microsoft 보고서 — AI가 인간 직원보다 더 비싸다 (axelk 측 자본·재무 차원 *기업 사례 실증*)

## 한 줄 요약
**Microsoft가 *Claude Code 직접 라이선스 대부분 취소·GitHub Copilot 전환*, Uber는 *2026 AI 코딩 예산 4개월 만에 소진*, Nvidia는 *컴퓨팅 비용이 직원 비용 초과* — *토큰 사용 장려 OKR이 청구액 증가 악순환*을 만들고, Goldman Sachs는 *에이전트 AI가 2030년까지 토큰 소비 24배 증가* 전망, Gartner는 *토큰 단가 90% 하락도 소비 증가가 앞지름* 예측**. *Is AI Profitable*의 *산업 적자*가 *개별 기업 차원에서 실증 도착*.

## 핵심 포인트

- **Microsoft *공급자 전환*** — Claude Code 직접 라이선스 *대부분 취소* → GitHub Copilot 전환. *자사 제품 활용 전략* + *외부 토큰 비용 절감* 두 동기. 댓글 지적: *기사 제목의 *AI 비싸다*는 Microsoft 공식 발언 인용 없음, 전략적 선택 측면 더 큼*.
- **Uber *예산 4개월 소진*** — *2026 AI 코딩 도구 예산이 1/3 시점에 100% 소진*. *연간 예산 모델*이 *에이전트 시대 토큰 소비 동학*에 맞지 않음의 직접 증거.
- **Nvidia *컴퓨팅 > 직원 비용*** — Bryan Catanzaro (응용 딥러닝 부사장): *내 팀에서는 컴퓨트 비용이 직원 비용을 훨씬 넘어선다*. *AI 회사 자신*도 *AI 비용에 시달림*의 역설.
- **토큰 사용 OKR이 *Goodhart 위반*** — 댓글 지적: *기업이 토큰을 최대한 태우라는 OKR 도입*이 청구액 폭증 원인. **[[2026-05-17-amazon-token-burning-goodharts-law]]의 *직접 반복 사례*** — *AI-Goodhart 수퍼휴먼 가속* 가설 *현장 실증*.
- **Goldman Sachs *2030 토큰 소비 24배*** — *에이전트 AI = 기하급수 토큰 소비*. [[2026-05-18-ai-subscription-pricing-truth]]의 *State of Brand 진단*과 *수치적 일치*.
- **Gartner *단가 하락 ≠ 비용 절감*** — *토큰 단가 90% 하락에도 소비 증가가 앞지름*. **Jevons 역설의 AI 토큰 차원** — 가든의 [[2026-W21-geeknews-359]]에서 식별한 *Cal Newport 제번스 역설*의 *Gartner 수치적 실증*.
- **에이전트 미래 = *예상보다 훨씬 무거운 비용*** — 경영진 *연간 예산·고정 ROI 가정*의 *근본 재설계 필요*.
- **댓글 *제목 오해 비판*** — *Microsoft가 AI가 직원보다 비싸다고 말했다는 인용은 실제로 없음*. *기사 자체가 Goodhart 매체 차원* (헤드라인 KPI에 맞춰 본문 왜곡). **[[2026-05-20-greg-wilson-twelve-ways-ai-coding-measurement-wrong]] *Wilson 12 잣대*의 *언론 보도 차원 적용 사례***.
