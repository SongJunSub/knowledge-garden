# AWS — 4년 그리고 퇴사 (axelk 측 노동·조직 부식 차원 후보 1번째 자산)

> 출처: adventuresinoss.com (GeekNews 경유) · 정리일 2026-05-25

## 한 줄 요약
**AWS 4년 근무 후 퇴사한 개발자의 회고 — *고객 문제 해결 중심의 S3·EC2·RDS 같은 인프라에서 GenAI로 급격히 초점 이동*하면서 *AI 콘텐츠 강요·"충분히 괜찮음" 태도 확산·AI 봇 도입으로 지원 품질 하락·잇단 해고로 조직 지식 축적 불가능·우수 인력 이탈*. 개인적으로는 *체중 증가·혈압 상승·수면 장애* 신체 건강 악화. 결론: *오픈소스로 회귀, 기술적 힘과 통제를 벤더가 아닌 사용자 손에***.

## 핵심 포인트

- **AWS의 *대체 가능 인력* 관점 IT 조직 적용** — Amazon 본사의 *retail 노동 관점*이 *고도 전문성 IT 조직에 부적절하게 확장*. 댓글: *Jassy CEO 승격 후 Charlie Bell 등 주요 리더 이탈 시점부터 본격화*.
- **GenAI 중심 급격 전환** — *고객 문제 해결 중심 인프라 서비스 (S3·EC2·RDS) → GenAI 카탈로그*. 자원 배분 우선순위 *조직 차원 재편*.
- **AI 콘텐츠 강요로 *충분히 괜찮음* 태도** — 직원이 *AI 생성 콘텐츠 사용 강요*받으며 *고객 중심성 훼손*. **[[2026-05-21-comeau-ai-amplifies-existing-skills]] Comeau *Iron Man 슈트* 명제의 *조직 강요 어두운 면***.
- **AI 봇 = 지원 품질 추락** — 댓글: *7일 미배정·1차 무능·AI 생성 장문 잘못된 답변* 사례. *검증되지 않은 응답은 거의 무시*. **고객 측 axelk 자산의 인간 차원 시연**.
- **해고 → 조직 지식 손실 악순환** — *잇단 해고로 조직 지식 축적 불가능 + 우수 인력 지속 이탈*. **[[2026-05-14-naur-programming-as-theory-building]] *프로그램 = 이론 = 보유자 흩어지면 죽음*의 조직 차원 시연**.
- **개인 건강 악화 명시** — *체중 증가·혈압 상승·수면 장애*. *조직 부식이 개인 신체에 직접 도착*하는 *희귀 인간 차원 데이터*.
- **오픈소스로 회귀** — *벤더 통제 → 사용자 손*. **[[2026-05-21-axelk-ai-is-plagiarism-at-scale]] *법적·경제* + [[2026-05-21-susam-dont-roll-your-own-web-ui]] *기본기 회귀 라인*과 *3 자산 합류*** — *통제권 회복*이 *콘텐츠·기술·인력 3 차원에서 동시 주제*.
- **댓글: *Charlie Bell 이탈 = 분기점*** — *MBA 경영진이 엔지니어링을 비용 항목으로만 봄*. **[[2026-05-21-dorsey-ai-native-organization]] *Dorsey 모델*의 *그림자 측 변형*** — Dorsey는 *위계 해체*인데 AWS는 *전문성 비용 절하*. *같은 메커니즘의 좋은 변형 vs 나쁜 변형*.
