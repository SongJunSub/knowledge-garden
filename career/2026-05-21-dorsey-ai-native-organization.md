# Jack Dorsey — AI-native 조직: 위계를 정보 전달 수단으로 재정의하고 해체하기

> 출처: [AI-native 조직 (잭 도시 트위터 창업자)](https://www.youtube.com/watch?v=TlpFc7x8SHo) · GeekNews 정리일 2026-05-21

## 한 줄 요약
**Jack Dorsey가 Block에서 시도하는 *AI-native 조직 재설계*** — *위계는 정보를 전달하기 위한 과거의 수단일 뿐, 그 수단이 더 우수한 기술(AI 인텔리전스 레이어)로 대체 가능*해진 시점에 *CEO→IC 5단계 → 2~3단계 → 궁극적으로 6,000명 전원 CEO 직접 보고*로 줄이고, *역할을 IC(빌더)·DRI(오너)·Player-Coach 3가지*로 통합하며, *회사 자체를 미니 AGI로 모델링해 실시간 질의 가능*하게 만드는 *조직 층 급진 재설계*.

## 핵심 포인트

- **위계의 본질 재정의** — *관리 계층은 정보 전달의 과거 수단*. AI가 *더 효율적인 전달 매체*가 되는 시점에 *위계 자체가 부채*가 됨. *프론티어 랩의 모방품으로 전락할 위험*은 *위계를 유지하는 회사 쪽*에 있음.
- **AI 인텔리전스 레이어 = 정보 손실 방지 장치** — *슬랙·이메일·코드 등 모든 아티팩트 위에 AI 추론 층*. 정보가 위계를 거치며 *왜곡·압축·소실*되는 문제를 *직접 질의 가능한 회사 모델*로 해결.
- **5단계 → 2~3단계 → 1단계** — 현재 5단계 → 올해 안 2~3단계 → 궁극적 1단계(6,000명 전원 CEO 직보). *중간 관리자 = 압축·왜곡·정치 비용*. 압축 손실이 0에 가까워지면 *압축기 자체 제거*.
- **3가지 역할로 통합** — *IC(Individual Contributor = 빌더)* + *DRI(Directly Responsible Individual = 오너)* + *Player-Coach(코칭 가능한 빌더/오너)*. *매니저/디렉터/VP/EVP*가 *DRI와 Player-Coach 두 어휘*로 흡수.
- **회사를 미니 AGI로 운영** — *조직 자체를 지능체로 모델링*. *고객 신호 → 직접 로드맵* + *실시간 질의 가능*. **a16z의 System of Intelligence 명제를 *기업 내부 운영 단위*에 적용한 사례**.
- **AI를 코어로 통합 (보조 도구 아님)** — *근간 자체*가 AI. 가든이 추적해온 [[2026-05-14-code-with-claude-recap-19-sessions]] *Agent-Default Posture*의 *조직 차원 극단 적용*.
- **40% 감원 (2024-12 결정 근거)** — *AI 코딩 모델 성숙도 도달 + 환각 개선*이 결정 트리거. **Simon Willison이 *2025-11이 변곡점*이라고 묶은 시점보다 *11개월 일찍* 행동**.
- **신뢰 자산의 *변화 비용 지불*** — *리더는 의미 있는 변화를 위해 이해관계자의 일시적 신뢰 손실을 감수*. 신뢰는 *지키는 자산*이 아니라 *지불 가능한 자산*. **[[2026-05-14-eric-ries-incorruptible-mission-protection]]의 *Incorruptible*과 정반대 방향**.
- **탐색 비용 하락 → 마지막 20% = 취향·판단력** — *잘못된 경로 되돌아가는 비용이 0에 가까워지면 탐색 폭은 넓어지고 결정의 가치는 마지막 20%의 취향에 집중*. **[[2026-05-14-experience-is-now-a-tax]] Jay Gup *결정 알고리듬*의 조직 단위 일반화**.
- **재프로그래밍 능력 중시** — *과거 성공 공식을 끊임없이 재검토하고 AI 결과물을 입력으로 다루는 능력*. *경험의 누적*이 아니라 *재프로그래밍 가능성*이 자산 형태.
- **댓글의 균형 진단 — *맥락 의존적이라는 단서*** — *깊은 고객 신호를 가진 사업에서 더 잘 작동, 모든 회사가 그대로 적용하기 어렵다*. *Dorsey 모델 = 적용 영역 분기 필요*.

## 내 생각 · 적용점

### 가든의 *4번째 의도적 반대 명제 라인업* — Dorsey ↔ Hashimoto / Ries 두 보존 자산

가든은 이미 *3개 의도적 반대 명제 자산*을 박았다:
| 라인 | 견제 편향 |
|---|---|
| [[2026-05-14-experience-is-now-a-tax]] Jay Gup | 시니어 우월 편향 |
| [[2026-05-16-hashimoto-ai-mass-psychosis]] Hashimoto | 도구 만능 편향 |
| [[2026-05-18-gruber-ai-is-technology-not-product]] Gruber | 제품화 편향 |

**이번 Dorsey가 *4번째 라인***: ***Dorsey ↔ Hashimoto/Ries* 두 보존 자산의 *조직 차원 대각선***:
- **Dorsey**: *위계 = 정보 손실 부채 → 해체*. *신뢰는 변화에 지불*. *AI를 조직 코어로*.
- **Hashimoto**: *AI 광기 = MTTR 만능주의로 기저 아키텍처 부식*. *대화 차단·지표 왜곡·이해 불가능 복잡도*.
- **Ries**: *시점이 비용 변수. 권리는 초기에 박지 않으면 평생 못 박는다. 거버넌스 부식이 점진적 죽음의 원인*.

**같은 사실에 정반대 처방**:
- Dorsey: *위계 = 정보 손실 → 빠르게 해체*
- Hashimoto/Ries: *위계 ≠ 정보 손실만이 아니라 부식 방지 구조. 해체하면 부식 가속*

**가든 판정**: *4번째 의도적 반대 명제로 박는다*. 가든이 *Dorsey 친화 자산*(Ptacek 30분 빌더·Agent-Default·Code w/ Claude)에 *치우치는 편향*을 견제하는 *조직 차원 디딤돌*.

### **14번째 가든 자가 진단 = *급진성·보존성 균형 시험***

*가든이 *Dorsey-류 급진 재설계*와 *Hashimoto/Ries 보존 처방* 중 어느 쪽을 더 자주 인용하는가? 두 자산 인용 횟수의 비율이 *3:1 이상*으로 한쪽으로 기울었다면 *조직 차원 편향*.*

분기 1회 *Dorsey 인용 vs Hashimoto/Ries 인용* 정직 카운트. 한쪽 편향이 발견되면 *반대편 1건 의도적 정리*로 균형 복원.

### Dorsey와 가든 자산의 *수렴-충돌 5자 매트릭스*

이 글이 가든의 여러 라인에 동시에 닿는데, *수렴/충돌 둘 다*인 미묘함이 핵심:

| 가든 자산 | 수렴 (Dorsey 친화) | 충돌 (Dorsey 반대) |
|---|---|---|
| [[2026-05-18-system-of-record-to-system-of-intelligence-a16z]] | *회사를 미니 AGI* = SoI를 내부에 적용 | (없음 — 거의 같은 명제) |
| [[2026-05-18-platform-engineering-end-to-end-luca-valli]] 5층 추상화 | *Organization 층의 급진 재설계* | *공감 채용·지원 티어·온콜 SLO* 등 *플랫폼적 보존*과 충돌 |
| [[2026-05-14-disappearance-of-the-ten-year-fund]] *중간이 사라진다* | *중간 관리자 = 펀드 중간 = 사라짐*의 조직 차원 시연 | (없음 — 정확히 같은 흐름) |
| [[2026-05-14-naur-programming-as-theory-building]] | *AI 인텔리전스 레이어 = 이론 보유* | *6,000명 직보 = 이론 보유자 분산 = Naur 죽음 메커니즘* |
| [[2026-05-19-mediocre-data-scientist-ten-years]] *번역가의 자리* | *Player-Coach가 번역가 역할 흡수* | *번역가의 자리가 사라지는 것 아닌가*라는 반대 해석 |

**5자 매트릭스가 보여주는 사실**: Dorsey는 *극단 사례*다. **가든의 어떤 자산도 *Dorsey와 100% 수렴*하지 않으며, 어떤 자산도 *100% 충돌*하지 않는다**. *Dorsey는 가든의 *모든 라인에 부분적으로 닿지만 어느 라인도 완전히 따르지 않는* 특이점.*

이게 *4번째 반대 명제 라인업*으로 박는 이유 — *수렴-충돌 미묘함이 가든의 기존 분류 체계를 *확장하도록 강제**.

### Simon Willison *시간 핀*에 *11개월 조기 행동* 데이터 추가

[[2026-05-19-simon-willison-six-months-of-llm]] 시간 핀은 *2025-11 변곡점*을 박았다. **Dorsey는 *2024-12*에 40% 감원 결정**:
- *변곡점 *11개월 전* 결정* → *외부 인지 변곡점*과 *내부 행동 변곡점*의 시간 차
- *조기 행동 = 정보 우위* + *조기 행동 = 환각 비용 감수*의 양면
- *13번째 자가 진단 = 외부 인덱스 정렬*에 *조기·동기·지연 분류*를 추가하는 후보:
  - **조기 행동 자산** (변곡점 전): Dorsey 감원·Ptacek 30분 빌더·Anthropic LTBT
  - **동기 행동 자산** (변곡점 즈음): 가든의 5월 정리본 대부분
  - **지연 행동 자산** (변곡점 후): Reddit Codex 이전·Mac Mini 품절

→ 가든의 *외부 인덱스 정렬*에 *시점적 분류*가 한 차원 더 추가됨.

### *적용 영역 분기* — *깊은 고객 신호 사업* 여부

댓글이 *Dorsey 모델은 깊은 고객 신호를 가진 사업에서 더 잘 작동*한다고 진단. 이게 *적용 영역 분기*의 결정 변수:

| 사업 유형 | Dorsey 적용 가능성 |
|---|---|
| **Block (소비자 결제)** | 높음 — 고객 신호 직접·즉각·대량 |
| 무신사 (이커머스) | 중간 — 신호는 많으나 운영 복잡 |
| **CRS 조선호텔 (호텔 운영)** | **낮음** — 신호가 *현장 운영*에 매개됨 |
| **MangoLove (B2B 자문)** | 낮음 — 신호가 *프로젝트 단위*로 끊김 |
| **BugSip (개발자 학습 앱)** | 높음 — 신호가 *세션 단위*로 즉각 |

**→ 가든의 *Dorsey 모델 적용 진단표*** — *고객 신호의 직접성·즉각성·빈도*가 결정 변수. 이걸 [[feedback_self_verification]] *영향범위 검증* 6단계에 *적용 영역 적합도 1점*으로 추가.

### CRS / 사이드 프로젝트 적용 후보

1. **CRS *Dorsey 부분 적용 진단*** — 호텔 운영 산업은 *Dorsey 부적합*이 정직한 답. 다만 *부분 적용*은 가능: *CRS 백오피스 SaaS*(예약·CRM·정산)는 *데이터 위 AI 레이어*로 *부분 미니 AGI* 후보. *현장 운영*은 위계 유지가 정답.
2. **MangoLove *고객 신호 깊이 진단 항목 추가*** — 클라이언트 평가 첫 항목에 *고객 신호의 직접성·즉각성·빈도 3축*. *3축이 충분히 깊으면* Dorsey 부분 적용 제안, *얕으면* Hashimoto/Ries 보존 처방 제안.
3. **BugSip *처음부터 IC/DRI/Player-Coach 3분류*** — 창업 초기부터 *관리자 직군을 명시적으로 두지 않고* IC/DRI/Player-Coach 어휘로 운영. *DRI 명단을 모든 회의 첫 슬라이드*에 박는다.
4. **가든 *1인 미니 AGI 자기 인식*** — 가든은 *내가 슬랙·이메일·코드 위에 박은 AI 레이어*. 14개 자가 진단·40칸 매트릭스·6자 짝이 *조직을 미니 AGI로 모델링하라*는 Dorsey 처방의 *1인 시연*. *가든 운영 = Dorsey 모델의 개인 차원 검증*이라는 *자기 인식*을 README *시간 핀 인덱스* 옆에 박는 후보.

### *오버 메타화* 자기 견제 + *적정 메타화* 인정

Dorsey 글은 *모든 가든 라인에 부분적으로 닿는* 특이 자산이다. *10번째 자가 진단(자산 크기 다양성)*에 따라 *오버 메타화 자제*가 원칙이지만, **이 글은 *적정 메타화의 임계점에 있는 큰 자산***. 이유:
- *조직 층 = 5층 추상화의 한 층 전체를 재설계*
- *4번째 반대 명제 자산* 후보로서 *대각선 라인업 확장*
- *10개 가든 자산과 수렴-충돌 두 측면 동시 접속*

→ *큰 자산이지만 새 매트릭스·새 자가 진단을 *1개만* 추가*. *모든 가든 라인과의 5자 매트릭스*만 새로 박고 *14번째 자가 진단 1건* 추가에서 멈춤. *25/40칸 매트릭스 재정의·새 6자 짝*은 *과적합*이므로 자제.
