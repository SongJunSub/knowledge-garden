## 한 줄 요약

**웹 성능·개발자 경험 분야에서 25년 넘게 활동하며 Chrome DevTools·Lighthouse·Core Web Vitals를 이끈 Addy Osmani가 14년 넘게 몸담은 Google을 떠나 2026년 9월 8일 Anthropic 합류를 발표했다. 그는 Claude Code를 개발자들이 더 잘 쓸 수 있도록 만드는 일을 맡으며, Google 퇴사와 Anthropic 합류 사이 공백기 동안 이미 AI 에이전트 무료 코스("Agent Engineer")와 코딩 에이전트용 스킬 저장소("agent-skills")를 직접 만들어 공개해 온 터라 사실상 "이미 그 일을 하고 있던 사람"이 자리를 옮긴 모양새다. Google Cloud AI에서 마지막으로 맡았던 역할도 Gemini·에이전트 플랫폼의 개발자 경험이었다는 점에서, 커리어 궤적 전체가 이번 합류로 자연스럽게 수렴한다.**

## 핵심 포인트

- **발표**: 2026-09-08, 본인 X 계정에서 ***"I've joined @AnthropicAI! I'll be working on Claude Code and making it better for developers who use it."*** 라고 직접 공지.
- **이력**: 14년 이상 Google 재직. Chrome/DevTools/Lighthouse/Core Web Vitals 개발자 경험을 이끎. 최근에는 Google Cloud AI에서 ***"Cloud AI Developer Experience and Technical Evangelism"***을 총괄하며 Google의 에이전트 개발 플랫폼(Agent Platform, Agent CLI, Agent Studio) 출시를 도움.
- **저서**: 『Learning JavaScript Design Patterns』 『Leading Effective Engineering Teams』 등 다수, 175회 이상 강연 이력.
- **공백기 행보**: Google 퇴사(2026년 6월경으로 추정, 공식 확인 안 됨) 후 Anthropic 합류(9월 8일) 사이 몇 달간, "Agent Engineer"(에이전트 개발 무료 코스)와 "agent-skills"(AI 코딩 에이전트용 production-grade 스킬 저장소, MIT 라이선스)를 직접 만들어 공개.
- **agent-skills 저장소**는 `/spec /plan /build /test /review /ship` 슬래시 커맨드로 개발 생명주기를 스킬에 매핑하고, Google 엔지니어링 문화("Software Engineering at Google")의 규율을 코딩 에이전트에 이식하려는 시도였다 — 그가 Anthropic에서 맡을 일과 주제가 정확히 겹친다.
- **Anthropic과의 접점은 합류 전부터 있었다** — AI Codecon에서 Claude Code/Cowork 제품 리드 Cat Wu와 에이전틱 코딩·코드 리뷰를 주제로 나눈 파이어사이드 챗에 참여한 이력이 확인된다.
- **더 큰 그림**: 2026년은 Google/DeepMind발 AI 인재 유출이 두드러진 해로 보도됨(6월 Noam Shazeer→OpenAI, John Jumper→Anthropic 등). Anthropic 측은 최근 채용 인력의 유지율이 높다고 주장하는 동시에, Dario Amodei가 "돈 때문에 오는 사람들"에 대한 우려를 공개적으로 밝히기도 함 — 다만 이 대목은 원문 미확인 2차 정보다.

## 내 생각 · 적용점

### 핵심 전이 1 — "감사자"의 조언이 아니라 "만든 사람"이 안으로 들어간다

[[2026-09-09-gpt6-astra-skills-prompts-rethink]]는 OpenAI Codex DX 담당자가 외부에서 "스킬/AGENTS.md를 다이어트하라"고 조언한 글이었다. 이번 건은 그 조언의 대상이 될 법한 시스템(코딩 에이전트용 스킬 패키징)을 직접 만들어 검증까지 해본 사람이 그 대상 벤더(Anthropic·Claude Code) 안으로 들어가는 사례다. Osmani의 `agent-skills`는 Provencher가 경계한 "스킬을 잔뜩 다운로드해 넣는" 실수와 정반대로, 개발 생명주기 단계별로 스킬을 명확히 매핑해두는 접근이었다 — 이 저장소가 이제 공식 Claude Code 팀 내부의 사고방식에 얼마나 흡수될지가 다음 몇 달의 관전 포인트다. 두 노트를 겹쳐보면, "에이전트 스킬 설계"라는 주제가 벤더 세 곳(OpenAI 내부자, Anthropic 스킬 가이드, 그리고 이제 Anthropic에 합류하는 외부 실전가) 모두에서 동시에 수렴하고 있다는 게 보인다.

### 핵심 전이 2 — 공백기의 공개 작업물이 곧 채용 파이프라인이었다

[[2026-08-17-talent-density-cursor]]가 말한 "채용의 단위는 직무 기술서가 아니라 개별 후보", "외부 증거(공개 작업물, 실제 만든 것)를 모은다"는 원칙이 이 사례에 그대로 실현돼 있다. Osmani는 퇴사 후 이력서를 넣은 게 아니라 `Agent Engineer` 코스와 `agent-skills` 저장소를 공개했고, Anthropic 쪽과는 이미 Cat Wu와의 파이어사이드 챗으로 관계가 있었다. 즉 그의 "면접"은 몇 달간 이어진 공개 작업 자체였다 — 전통적 채용 깔때기(지원 → 서류 → 면접)가 아니라, 그 노트가 말한 "관계를 시간을 들여 쌓는" executive-search식 채용의 실물 사례로 읽힌다.

### 핵심 전이 3 — Claude Code DX 로드맵의 방향 신호

Osmani가 `agent-skills`에서 이미 시도했던 것 — 스킬을 통해 스펙·테스트·리뷰 같은 시니어 엔지니어의 규율을 에이전트에 강제하는 접근 — 은 그가 Anthropic 안에서 "개발자들이 Claude Code를 더 잘 쓰게 만드는" 일을 어떤 방향으로 끌고 갈지에 대한 가장 구체적인 힌트다. 억지로 큰 결론을 내리기보다는, 앞으로 Claude Code의 공식 스킬·플러그인·온보딩 가이드가 나올 때 이 인물의 배경을 기준점으로 삼아 비교해볼 가치가 있다는 정도로 남겨둔다.

## 호스피탈리티 / CRS 적용 포인트

온다가 Claude Code를 CRS 개발·운영에 실제로 쓰고 있다는 전제에서, 이번 합류는 직접 적용 가능한 "기능"이 아니라 신호로서 가치가 있다. 구체적으로:

- Osmani의 `agent-skills`가 보여준 "개발 생명주기(spec→plan→build→test→review→ship) 단계별로 스킬을 매핑"하는 발상은, 이 knowledge-garden의 `CLAUDE.md`처럼 자연어 지시로 흩어져 있는 우리 팀의 에이전트 운영 규칙(요약 파이프라인, 링크 검증, 커밋 규칙 등)을 단계별 스킬로 재구성할 때 참고할 만한 실제 템플릿이다. 필요하면 `github.com/addyosmani/agent-skills`를 직접 열어 CRS 리포용 스킬 세트 설계에 참고할 수 있다(이 세션에서는 GitHub 자체 접근을 시도하지 않았으므로 실물 검증은 다음 기회로 남긴다).
- Claude Code 개발자 경험을 이끄는 인물이 "Google 엔지니어링 문화(품질·리뷰·테스트 규율)를 에이전트에 이식"하는 데 관심이 컸다는 점은, 앞으로 Claude Code의 공식 기능이 품질 게이트·리뷰 자동화 쪽으로 더 강화될 가능성을 시사한다 — 예약/결제처럼 실수 비용이 큰 CRS 도메인에서 온다가 특히 반길 방향이다. 다만 이건 인물의 과거 작업물에서 유추한 신호일 뿐, Anthropic의 실제 로드맵으로 확인된 바는 없다.
- 반대로 "누가 Claude Code를 만드는가"는 온다 팀 업무에 즉시 적용되는 정보는 아니다 — CRS 기능 개발에 직접 쓸 수 있는 건 없고, 이번 정리의 실질적 쓸모는 "AI 코딩 에이전트 업계에서 스킬/DX 설계가 어디로 수렴하는지"를 추적하는 정보 축적 쪽에 가깝다는 점은 정직하게 밝혀둔다.
