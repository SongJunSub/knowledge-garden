# Window Sweaters — macOS 창에 뜨개질 무늬 테두리를 입히는 무료 오픈소스 앱

> 출처: [OSXDaily](https://osxdaily.com/2026/09/18/fun-stylize-mac-cozy-window-sweaters/) · WebSearch로 macg.co(프랑스어), 중국어 블로그 등 복수 리뷰 교차확인 · GeekNews [id=36669](https://news.hada.io/topic?id=36669) 경유 · 정리일 2026-11-06

**출처 한계**: news.hada.io 차단으로 GN⁺ 요약을 직접 열지 못했고, 개발자(saragordic)의 GitHub 저장소 원문도 이 세션에서 직접 확인하지 못했다. 아래 내용은 2026-09 시점의 리뷰 기사 3건(영어·프랑스어·중국어)이 공통으로 서술하는 내용을 교차확인한 것이다.

## 한 줄 요약

**macOS 창마다 다른 색상·패턴의 "뜨개질 스웨터" 테두리를 입혀주는 순수 장난감 메뉴바 앱.** 생산성 효용은 없지만 무료 오픈소스(GPL-3.0)이고 가볍게 다룰 만한 리소스 글이다.

## 핵심 포인트

- **기능** — 앱마다 다른 색상·패턴의 가상 "뜨개질 테두리"를 창에 둘러, 데스크톱을 포근하게 꾸밀 수 있음. Finder, Spotify, Claude, Codex 등 **37개 이상 앱의 전용 디자인**을 제공하며, 나머지 앱은 아이콘에서 색상을 추출.
- **커스터마이징** — 패턴, 테두리 두께, 뜨개질 스티치 크기를 조절 가능. "By App"은 앱별 고유 디자인, "Zigzag"는 앱 색상에 맞춘 통일된 지그재그 무늬를 적용하는 등 디자인 카탈로그에서 비교 가능.
- **요구 사항·설치** — macOS 13 이상, Intel Mac도 지원. Apple 서명이 없어 Gatekeeper가 막을 수 있어 시스템 설정에서 별도 허용이 필요. Homebrew(`brew install --cask saragordic/tap/window-sweaters`) 또는 GitHub Releases ZIP으로 설치.
- **라이선스** — GitHub(`saragordic/window-sweaters`)에 GPL-3.0로 공개, 기여자는 아직 1명 수준의 개인 프로젝트.
