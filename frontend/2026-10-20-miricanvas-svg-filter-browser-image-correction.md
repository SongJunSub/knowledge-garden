## 한 줄 요약

**미리캔버스(미리디)가 feColorMatrix·feComponentTransfer 같은 SVG 필터 프리미티브로 별도 이미지 처리 라이브러리 없이 브라우저에서 실시간 색상 보정을 구현했고, CSS 필터보다 정교한 제어와 GPU 가속을 통해 대용량 이미지 처리 성능까지 챙겼다는 사례다.**

## 핵심 포인트

- **구체적 필터 프리미티브** — ***feColorMatrix와 feComponentTransfer***를 사용해 브라우저 내 실시간 색상 보정을 구현했다. 이번 Slack 발췌는 9월 노트 때보다 구체적인 기술 명칭을 담고 있어, 같은 주제를 다룬다면 이번이 더 상세한 발췌일 가능성이 있다.
- **CSS 필터보다 정교한 제어** — CSS 필터(`filter: brightness()` 등) 대비 ***더 정교한 파라미터 제어***가 가능하다고 명시한다. feColorMatrix는 5x4 행렬로 RGBA 채널을 직접 변환할 수 있어 단순 밝기·대비 프리셋보다 세밀한 보정이 가능하다는 일반 지식과 부합한다(이 글 고유의 수치는 확인 못함).
- **GPU 가속과 성능** — ***GPU 가속을 활용해 대용량 이미지 처리 시 성능 최적화***를 달성했다고 한다. SVG 필터는 브라우저 렌더링 엔진이 GPU로 오프로드할 수 있어, 서버 왕복이나 Canvas 픽셀 연산보다 가벼울 수 있다는 방향이다.
- **인터랙티브 피드백** — 필터 파라미터를 ***동적으로 변경***해 사용자에게 즉각적인 시각적 피드백을 주는 인터랙티브 환경을 만들었다 — 디자인 툴(슬라이더 조작) 특성상 당연히 필요한 요구사항이다.
