## 한 줄 요약

**Opus 5.5에 같은 포켓몬 앱을 12개 JavaScript 프레임워크 조합으로 똑같이 구현시켰더니, 결과물의 Lighthouse 접근성·성능 점수는 거의 동일했지만 API 비용은 Hono+htmx 2.67달러부터 Angular 4.97달러까지 거의 2배 차이가 났다 — 같은 모델, 같은 과제인데도 프레임워크의 문서 구조와 생성 코드량이 AI 개발 비용에 실질적 영향을 준다는 뜻이다.**

## 핵심 포인트

- **실험 설계** — ***"Opus 5.5에 같은 포켓몬 앱을 12개 프레임워크 조합으로 구현하게 하고, 개발 비용과 시간, 코드량, 성능과 접근성을 비교"***했다. 동일한 모델·동일한 과제를 프레임워크만 바꿔 반복한 비교 실험이다.
- **비용 차이는 거의 2배** — ***"실행당 API 환산 비용 중앙값은 Hono+htmx 2.67달러, Angular 4.97달러"***였고, SvelteKit과 Gracile+Lit도 상대적으로 비쌌다. 같은 작업인데 프레임워크 선택만으로 AI 개발 비용이 2배 가까이 벌어질 수 있다는 뜻이다.
- **개발 시간도 2배 차이** — ***"개발 시간은 Astro 8.2분, Hono+htmx 8.6분, Angular 17.2분"***이었으며, ***"문서 탐색과 생성 코드량이 비용 차이에 영향을 줬을 가능성이 있다"***고 분석한다 — 즉 AI가 프레임워크 문서를 더 많이 참조하거나 더 긴 코드를 생성할수록 토큰 소비(=비용·시간)가 늘어난다는 추정이다.
- **결과물 품질은 거의 동일, 숨은 지표는 다르다** — ***"Lighthouse 접근성은 모두 100점, 성능은 97~100점"***으로 거의 동일했지만, ***"JavaScript 전송량과 로딩 지표에는 차이가 있었다"***고 발췌가 이어지다 끊긴다. 겉으로 보이는 Lighthouse 점수만으로는 프레임워크 간 실질적 차이(번들 크기, 실제 로딩 체감)를 포착하지 못한다는 암시다.

## 내 생각 · 적용점

**핵심 전이 — "AI가 쓰는 코드량·문서 탐색 비용"이 프레임워크 선택의 새로운 변수로 등장했다.** [[2026-09-26-when-ai-writes-almost-all-code]]가 "검증과 안목이 가장 중요해진다"고 짚었는데, 이 실험은 그 이전 단계 — AI가 코드를 쓰는 과정 자체의 비용이 프레임워크마다 다르다는 사실을 수치로 보여준다. 프레임워크를 고를 때 "사람이 쓰기 편한가"뿐 아니라 "AI가 그 프레임워크로 작업할 때 비용·시간이 얼마나 드는가"가 새로운 평가축이 될 수 있다는 뜻이다.
