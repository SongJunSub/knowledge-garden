# Vorssaint — 여러 Mac 유틸리티를 하나로 모은 메뉴바 앱, 무료 오픈소스로 계정·구독·사용 추적 없이 로컬에서만 실행

> 출처: [Vorssaint](https://github.com/vorssaintapp/vorssaint-utils) (GitHub) · GeekNews(id=33174) 경유 · 정리일 2026-09-03

## 한 줄 요약

**앱별 음량 조절, 시스템/네트워크 모니터, 클립보드 히스토리, 화면 캡처·주석, 파일 쉘프, 앱 제거, 창 관리 등 따로 구매하던 여러 Mac 유틸리티를 하나의 메뉴바 앱으로 통합한 무료 오픈소스(GPL-3.0) 프로젝트. 계정·구독·사용 추적 없이 완전히 로컬에서 실행되며, 필요한 기능만 골라 켜고 끌 수 있다.**

## 핵심 포인트

- **통합 기능** — 앱별 음량 조절(개별 앱 볼륨을 100% 이상으로도 조정), 시스템/네트워크 모니터, 개선된 앱 전환기, 창 스냅, 클립보드 히스토리(텍스트·이미지·파일, 즐겨찾기·검색 지원), 화면 캡처·녹화(내장 편집기로 캡처·주석·편집·내보내기), 클리너, 앱 제거기, 파일 쉘프, 링크 클리너, 화면 꺼짐 방지 등.
- **완전 로컬 실행** — 계정 없음, 구독 없음, 사용 분석·추적 기능 없이 Mac에서 로컬로만 실행. 제거한 기능은 화면에서 사라질 뿐 아니라 CPU·메모리·전력을 전혀 사용하지 않음.
- **선택적 활성화** — 필요한 기능만 설치·활성화 가능해 메뉴바를 가볍게 유지할 수 있음. 재설치해도 이전 설정이 그대로 복원됨.
- **라이선스** — GitHub에서 GPL-3.0 라이선스로 완전 무료 제공.

## 내 생각 · 적용점

이 글도 리소스 계열의 가벼운 도구 소개다. 억지로 깊은 전이를 만들지 않되, 하나만 짚는다면: **"계정·구독·추적 없이 로컬에서만 실행"이라는 설계 철학**은 [[2026-08-13-ublock-origin-stops-chasing-facebook-ads]]가 다룬 "비영리·사용자 이익 우선" 소프트웨어 계열과 같은 방향이다 — 여러 유료 유틸리티(볼륨 믹서, 클립보드 매니저, 스크린샷 도구 등을 개별 구매하면 월 몇 달러씩 누적)를 무료 오픈소스 하나로 통합한다는 것은, 구독 피로(subscription fatigue)에 대한 실용적 반응으로 읽을 수 있다.
