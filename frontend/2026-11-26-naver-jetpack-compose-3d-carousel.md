## 한 줄 요약

**Jetpack Compose에 기성 3D 캐러셀 컴포넌트가 없어, 네이버가 3D 공간에서의 회전과 배치 로직을 직접 구현하고 복잡한 애니메이션 처리를 위해 Compose의 상태 관리와 그래픽 API를 효율적으로 활용해 사용자 인터페이스에 최적화된 커스텀 3D 캐러셀 컴포넌트를 만들었다는 개발기다.**

## 핵심 포인트

- **3D 공간의 회전·배치 로직을 직접 구현** — Jetpack Compose를 활용해 사용자 인터페이스에 최적화된 커스텀 3D 캐러셀 컴포넌트를 만들면서, ***3D 공간에서의 회전과 배치 로직***을 직접 구현했다는 핵심 작업.
- **입체적인 시각 경험 제공이 목표** — 단순 리스트가 아니라 사용자에게 ***입체적인 시각 경험***을 제공하는 게 목표였다는 서술.
- **Compose의 상태 관리·그래픽 API 활용** — 복잡한 애니메이션 처리를 위해 Compose의 상태 관리와 그래픽 API를 ***효율적으로*** 활용했다는 서술 — WebSearch로 확인한 업계의 일반 패턴(기성 컴포저블 부재 → `Layout` 컴포저블로 직접 측정·배치하거나 드래그 입력에 따라 yaw·pitch를 바꿔 원근 투영으로 3D→2D 변환)과 방향이 일치한다.
- **기성 컴포넌트의 공백을 직접 메운 사례** — WebSearch로 확인한 바, Compose 공식 `carousel` API는 창 크기에 따라 조정되는 스크롤 가능한 캐러셀을 제공하지만 ***3D 회전·투영 효과는 공식 지원 범위 밖***이다 — 이 글이 그 공백을 직접 메운 사례로 읽힌다.
