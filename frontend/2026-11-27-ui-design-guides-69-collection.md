# 1980년대부터 현재까지, UI 디자인 가이드 69종 모음 (GeekNews)

> 출처: [1980년대부터 현재까지, UI 디자인 가이드 69종 모음](https://news.hada.io/topic?id=37889) (GeekNews) · 정리일 2026-11-27

> **출처 한계**: `news.hada.io`가 egress 차단되어 원문·hada 댓글을 직접 열람하지 못했다. WebSearch로 Apple Human Interface Guidelines 아카이브(1980년 Lisa 표준부터 2012년 OS X까지), Microsoft Windows 스타일 가이드(1987년), GNOME HIG 등 유사 아카이브의 존재는 확인했으나, 이 글이 소개하는 "69종" 아카이브 자체(정확한 사이트·저자)는 특정하지 못했다.

## 한 줄 요약

**1980년대 초기 GUI부터 현재 공식 디자인 가이드까지 69종을 한곳에 모은 아카이브로, Apple·Windows·Android 같은 주류 플랫폼뿐 아니라 Amiga·NeXTSTEP·Newton·Palm OS 같은 사라진 플랫폼의 인터페이스 원칙까지 시대·회사별로 비교해볼 수 있게 해준다.**

## 핵심 포인트

- **69종의 UI 스타일 가이드 아카이브** — 데스크톱과 모바일 등 여러 플랫폼의 설계 지침을 시대·회사별로 비교할 수 있게 모은 컬렉션.
- **주류 3대 플랫폼의 전체 역사** — Apple, Windows, Android의 여러 시기별 지침을 제공하며, ***초기 Lisa·Macintosh부터 Aqua, iOS, Material Design, 현재 공식 가이드까지*** 포함.
- **사라진 플랫폼까지 포함** — Amiga, NeXTSTEP, Newton, Palm OS 등 과거 플랫폼뿐 아니라, CDE·OPEN LOOK·SGI 같은 ***UNIX 환경과 Java의 GUI 설계 문서***까지 수록.
- **자료 출처가 다양** — PDF, 웹사이트 미러, Internet Archive 등에서 긁어모은 것으로 서술되어, 원본의 보존 상태나 저작권 표기는 사이트마다 다를 수 있다.
- WebSearch로 확인된 유사 사례: Apple HIG의 경우 1987년판이 Internet Archive에 의해 2012년 디지털화됐다는 기록이 있어, 이런 아카이브형 자료가 실제로 존재하고 유통되는 방식과 부합한다.

## 내 생각 · 적용점

### 핵심 전이 — 레포에 많지 않은 "디자인 역사" 자료

이 레포에는 UI 디자인 역사를 다루는 노트가 많지 않다. 억지로 연결고리를 만들기보다, 이 글은 순수한 레퍼런스 아카이브로서 가볍게 소비할 자료로 분류한다. 연결 없음(선행 노트 없음).

### 적용점

플랫폼별 인터페이스 설계 원칙이 시대에 따라 어떻게 바뀌었는지(스큐어모피즘 → 플랫 디자인 → 다시 질감 복귀 등)를 한눈에 비교할 때 쓸 수 있는 레퍼런스. 새로운 디자인 시스템을 만들 때 "선배 플랫폼들이 같은 문제를 어떻게 풀었는지" 참고하는 용도로 유용하다.
