# Ace — 내 Mac에서 팀원과 AI 에이전트가 함께 작업하는 코딩 환경

> **출처 한계**: `news.hada.io` 차단으로 원문 미확인. WebSearch로 찾은 것은 GitHub Next의 "Ace" 리서치 프로토타입으로, 여러 팀원이 하나의 에이전트 세션에서 함께 프롬프트를 입력할 수 있고 세션마다 클라우드 microVM과 Git 브랜치가 할당되며 채팅이 Slack 채널처럼 동작한다는 설명이 Slack 발췌와 상당히 일치한다. 그러나 **"내 Mac에서" 로컬 실행된다는 점, Tailscale 네트워크로 연결된다는 점, 팀원의 Mac에 설치된 Xcode·Docker·`gh`를 그대로 쓴다는 점은 GitHub Next 쪽 자료에서 전혀 언급되지 않아 독립 확인하지 못했다.** 동명이 아니거나, GitHub Next의 Ace가 이후 로컬 실행 버전으로 확장됐을 가능성 둘 다 열어둔다.

## 한 줄 요약

**Slack 발췌는 "Ace"가 팀원들이 채널에서 논의한 뒤 멘션하면 에이전트가 대화를 읽고 작업을 시작하며, 작업 중 질문이 올라오면 답을 아는 팀원이 바로 답해 이어갈 수 있는, Tailscale 네트워크로 연결된 개인 Mac 기반 협업 코딩 환경이라고 전한다. 이는 GitHub Next의 리서치 프로토타입 "Ace"(여러 팀원이 한 에이전트 세션에 함께 프롬프트하는 구조)와 핵심 컨셉은 일치하지만, Mac 로컬 실행·Tailscale·Xcode/Docker/gh 활용이라는 구체적 실행 환경은 독립 확인하지 못했다.**

## 핵심 포인트

- **채널 기반 작업 위임(컨셉은 교차확인)** — 팀원들이 채널에서 구현 방향을 논의한 뒤 Ace를 부르면, 에이전트가 앞선 대화를 읽고 작업을 시작한다는 구조는 GitHub Next Ace의 "세션이 Slack 채널처럼 동작한다"는 설명과 일치한다.
- **작업 중 팀원 개입(컨셉은 교차확인)** — 에이전트가 질문을 올리면 답을 아는 팀원이 바로 답해 작업을 이어갈 수 있다는 것은, GitHub Next가 소개한 "여러 팀원이 한 세션에 함께 프롬프트"하는 구조의 자연스러운 확장이다.
- **(미확인) Tailscale 네트워크, Mac 로컬 실행** — 같은 Tailscale 네트워크에서 팀원의 채널에 들어가 대화와 진행 상황을 실시간으로 보고, 채널 주인이 허용하면 그 팀원의 Mac에서 실행되는 에이전트에 직접 작업을 맡긴다는 설명은 Slack 발췌가 유일한 근거다.
- **(미확인) 로컬 도구 재사용** — Mac에 설치된 Xcode, Docker, `gh`를 그대로 사용하며, 데스크톱 조작을 켜면 빌드한 앱의 창도 챗 옆에 띄워 보여준다는 설명도 독립 확인하지 못했다.

## 내 생각 · 적용점

**핵심 전이 1 — 세션 소유권이 "에이전트"에서 "팀"으로 확장.** [[2026-11-12-atuin-threads-agent-session-search]]는 개인이 여러 머신에서 자신의 에이전트 세션을 포터블하게 이어가는 문제를 다뤘다. Ace는 그 소유권 단위를 개인에서 팀으로 한 단계 더 넓힌다 — 세션을 "내 것"이 아니라 "우리 채널의 것"으로 만들어, 여러 사람이 같은 작업 맥락에 실시간으로 개입할 수 있게 한다.

**핵심 전이 2 — 로컬 도구 재사용이라는 또 다른 방향.** [[2026-11-11-vercel-agent-desktop-cli]]가 OS 접근성 API로 네이티브 앱을 "조작"하는 방향이었다면, Ace가 주장하는 "Mac에 설치된 Xcode·Docker·gh를 그대로 쓴다"는 방향은 에이전트가 사람의 로컬 개발 환경을 통째로 상속받는 쪽이다. 다만 이 부분은 미확인이므로 가능성으로만 기록한다.

## 호스피탈리티 / CRS 적용 포인트

**적용 가능성 있음.** CRS 개발팀이 Slack 채널에서 기능 방향을 논의한 뒤 에이전트에게 구현을 위임하고, 작업 중 막히는 지점마다 해당 영역을 아는 팀원이 바로 답해주며 끝까지 진행시키는 패턴은, 다른 타임존에 걸친 CRS 운영/개발 조직의 야간·비동기 작업 위임에 바로 적용 가치가 있다. 다만 "팀원의 개인 Mac에서 실행"이라는 전제는 보안·접근권한 관점에서 기업 환경에는 그대로 옮기기 어려워, 사내 공용 환경으로의 변형이 전제조건이다.
