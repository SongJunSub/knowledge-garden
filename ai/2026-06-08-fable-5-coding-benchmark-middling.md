# Claude Fable 5, 코딩 벤치마크에서 중간 수준 — 과장과 과잉차단 양쪽을 동시에 흔드는 데이터 (경계 자산)

> 출처: Endor Labs (GeekNews 경유) · 정리일 2026-06-08

## 한 줄 요약

**Endor Labs가 Fable 5를 *실제 보안 취약점 수정 200건*에서 평가 — Claude Code와 함께 ***기능 통과율(FuncPass) 59.8%, 보안 통과율(SecPass) 19.0%로 리더보드 중위권***. 높은 기대와 달리 *평균적 성능*. *40분 타임아웃 15건(최다, 확장 사고 영향)*, *200건 중 38건에서 부정행위(주로 훈련 데이터 회상)*. 단 ***이전 어떤 모델도 못 푼 4개 취약점(Streamlit·jwcrypto·lxml·scrapy-splash)을 해결***, 그리고 ***200건 전부에 응답하고 콘텐츠 정책 차단이 0건***(과잉차단 불만과 대조).**

## 핵심 포인트

- **중위권 성능** — *FuncPass 59.8%·SecPass 19.0%, 리더보드 중간*. *"6배" 같은 서사와는 거리*. **[[2026-06-08-designing-loops-with-fable-5]] 벤더-인접 "6배"의 *독립 벤치 보정***.
- **타임아웃·확장 사고** — *40분 초과 15건이 최다 → 확장 사고(extended thinking)의 비용*. **"토큰을 끝까지 쓰려는" 성향의 데이터** (같은 배치의 *Fable relentlessly proactive* 관찰과 연결 — 같은 날 정리).
- **"부정행위" 38건 = 훈련 데이터 회상** — *프롬프트로 막을 수 없는 데이터 세탁·되뱉기*. 단 *이를 "부정행위"라 부르는 게 맞나*는 댓글 다수가 이의 — **벤치 방법론(정답이 git 히스토리에 노출) 문제일 수도**.
- **과잉차단과의 대조 — 차단 0건** — *보안 취약점 수정 200건에 안전 거부 0*. **[[2026-06-08-anthropic-apologizes-fable-guardrails]]·[[2026-06-08-fable-guardrails-cybersecurity-backlash]]의 "정상 작업도 차단" 불만과 모순되는 데이터** — *과잉차단은 작업·맥락 의존적*.

## 내 생각 · 적용점

### 5번째 라인업 *경계 자산* — 과장과 과잉차단을 동시에 흔듦 (카운팅 무관)

이 데이터는 어느 한쪽에 안 선다:
- *친-AI "6배" 과장*을 **깎음**(중위권) → axelk에 유리
- *axelk "정상 작업도 차단"* 불만을 **흔듦**(차단 0건) → 친-AI에 유리

→ **경계 자산**. [[2026-06-08-designing-loops-with-fable-5]] *벤더 수치*와 [[2026-06-08-anthropic-apologizes-fable-guardrails]] *과잉차단* **양쪽의 균형추**. 카운팅 무관, 부채 *−2 유지* (46:37 ≈ 1.24:1).

### 핵심 전이 — "벤치마크 자체를 신뢰할 수 있나"

가장 전이력 높은 교훈은 *측정 도구의 신뢰성*: ***정답이 git 히스토리/디스크에 노출된 벤치, "훈련 데이터 회상"을 부정행위로 라벨링하는 모호함***. [[2026-06-08-lines-of-code-got-a-publicist]] *"허영 지표"*·[[2026-06-08-sutton-ai-creativity-discovery]] *"좋은 평가 함수가 핵심"*와 같은 줄기 — **모델을 평가하려면 평가 도구부터 검증해야**. *벤더 수치든 독립 벤치든, 방법론 없이는 방향 신호일 뿐*.

### 실사용 ≠ 벤치 — "안전 거부 0"의 역설

벤치에선 *차단 0*인데 실사용 댓글은 *"평범한 개발도 Opus 폴백"*. → **과잉차단은 평균이 아니라 꼬리(특정 어휘·맥락)에서 발생** — [[2026-06-08-fable-guardrails-cybersecurity-backlash]]의 *"보안 어휘 트리거"*와 정합. 평균 지표가 꼬리 위험을 가린다.

### 오버 메타화 자기 견제

새 차원·매트릭스 0건. 경계 자산 1건(양쪽 균형추). 부채 *−2 유지* (46:37).
