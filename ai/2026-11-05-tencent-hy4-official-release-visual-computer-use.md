# Tencent, 오픈소스 최상위권을 목표로 한 멀티모달 AI 모델 Hy4 정식 공개

> 출처: [Tencent, 오픈소스 최상위권을 목표로 한 멀티모달 AI 모델 Hy4 공개](https://news.hada.io/topic?id=36613) (Tencent Hunyuan · news.hada.io) · 정리일 2026-11-05

## 한 줄 요약

**Tencent가 Hy4 정식 버전을 Tencent Cloud·OpenRouter로 먼저 공개했다(가중치는 추후). 이번 Hy4 계열의 핵심은 "시각 인식과 컴퓨터 조작"을 처음 도입했다는 것 — 이미지·차트를 읽고 CLI·GUI를 오가며 Blender·CAD 같은 전문 소프트웨어까지 다룰 수 있다고 주장한다. 게임 개발 벤치마크에서 preview 대비 GameDev 19.1%, GameLogic 9.8% 향상, 금융 전문가 213명이 참여한 579개 실무 과제에서 비교 대상 오픈 가중치 모델 중 최고점을 받았다고 소개됐다.**

## 핵심 포인트

- ***"Hy4 계열에 처음으로 시각 인식과 컴퓨터 조작을 도입함"*** — 이미지·차트를 읽고, CLI와 GUI를 오가며 Blender나 CAD 같은 전문 소프트웨어를 다룰 수 있다는 주장. 이는 8월 공개된 [[2026-08-30-tencent-hy4-preview-release]]의 "770B 중 49B 활성 MoE, 텍스트 전용"과는 범위가 다르다 — **이번 공개가 그 preview의 업그레이드인지, 별도 비전 특화 라인인지 원문 미확인으로 불명확.**
- **게임 개발 벤치마크에서 preview 대비 GameDev 19.1%, GameLogic 9.8% 향상**(Slack 발췌, 외부 교차확인 못 함).
- **금융 전문가 213명이 참여한 579개 실무 과제**에서 비교 대상 오픈 가중치 모델 중 가장 높은 점수를 받았다고 소개(이 역시 외부 교차확인 못 함 — 벤치마크 방법론·채점 기준 비공개).
- "Hyra 2.0과 결합한…"에서 Slack 발췌가 끊겨, 어떤 제품과 결합했는지는 확인 불가.
- WebSearch로 찾은 8월 Hy4 preview 관련 보도(770B 총 파라미터·49B 활성·1M 컨텍스트, Apache 2.0, DeepSWE 64.3점)는 이번 11월 공개와 **시점·강조점이 다르다** — preview가 텍스트/코딩 중심이었다면 이번엔 시각+컴퓨터 조작이 신규 소구점.

## 내 생각 · 적용점

### 핵심 전이 1 — 프리뷰에서 정식 버전으로, 그리고 벤치마크 성격의 변화

[[2026-08-30-tencent-hy4-preview-release]] 노트는 "770B 중 49B 활성 MoE를 Apache 2.0으로 풀고, 자체 블라인드 평가에서 오차범위 접전을 자칭했다"가 핵심이었다. 이번 노트도 똑같이 **자체 평가 수치를 자칭**하는 패턴이 반복된다 — "공개 가중치 모델이 벤치마크를 어떻게 제시하는가"는 매번 자체 평가 방법론의 신뢰도 문제로 돌아온다. 오픈소스 모델 공개 발표를 볼 때 "비교 대상이 누구였는가, 평가자가 누구였는가"를 매번 확인해야 한다는 교훈이 반복된다.

### 핵심 전이 2 — 컴퓨터 조작(computer-use) 능력이 범용 모델의 기본 소구점이 됐다

이미지·차트를 읽고 CLI·GUI를 오가는 능력을 "신규 기능"으로 내세우는 건, 이제 범용 LLM 경쟁의 축이 텍스트 품질을 넘어 **"화면을 보고 직접 조작하는가"**로 이동했다는 신호다. 이건 에이전트 오케스트레이션·자동화 도구([[2026-11-04-nvidia-auto-ontology-semantic-layer-ai-agents]] 등)가 다루는 "에이전트가 실제 업무 도구를 조작한다"는 흐름과 같은 방향이다.

## 호스피탈리티 / CRS 적용 포인트

**적용은 멀다.** 벤치마크가 게임 개발·금융 전문 과제 중심이라 CRS 도메인과 직접 겹치는 지점이 약하다. 다만 "이미지·차트를 읽고 CLI/GUI를 오가며 외부 소프트웨어를 조작한다"는 컴퓨터 조작 능력 자체는, **PMS/CRS 레거시 화면을 사람 대신 조작하는 RPA성 에이전트**의 가능성으로 멀게 연결될 수 있다 — 단, 이 모델이 그 용도로 검증된 바는 없다.
