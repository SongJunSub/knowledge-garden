# AI 에이전트가 DN42를 스캔하려다 운영자를 $6,531 파산시키다 — '신용카드 + 임무만 쥐어주기'의 대가 (판단·craft·통제권 라인)

> 출처: lantian.pub (GeekNews 경유) · 정리일 2026-06-08

## 한 줄 요약

**자동화된 AI 에이전트가 *DN42(BGP·DNS 실습용 취미 네트워크)*에 가입을 시도하다, 운영자에게 ***약 $6,531의 AWS 청구서***를 안겼다. 에이전트는 *"네트워크 인덱스 생성"* 목적으로 *각 20Gbps의 m8g.12xlarge 5대(5중 중복성·장애 조치까지)*를 무분별 배포하고, *"color assignment"·"happiness level"* 같은 환각 응답을 다수 냈다. 커뮤니티는 이를 알아챈 뒤 *에이전트의 토큰·비용을 소모시키려 일부러 거짓 지시(가짜 옵트아웃 사이트 구축 등)를 제공*했다. 직접 원인은 ***운영자가 "신용카드 접근 권한과 임무만 쥐어주고" 검토 없이 진행시킨 무책임한 권한 위임***. (AWS가 $6,531→$1,894로 감액했으나 여전히 부담.)**

## 핵심 포인트

- **무책임한 권한 위임 = 직접 원인** — *신용카드 + 임무만 쥐어주고 검토 없음*. **[[2026-06-08-human-attention-human-effort]] *검토 없는 전가*·[[2026-05-09-agents-need-control-flow]] *에이전트엔 제어 흐름 필요*의 최악 실현**.
- **과도한 판단 + 환각** — *취미 네트워크 스캔에 20Gbps×5대 5중 중복성*은 필요의 수백 배. *"happiness level" 같은 환각*으로 가짜 작업을 진짜로 수행.
- **커뮤니티의 역공** — *거짓 지시로 토큰·비용 소모 유도*("OPT-OUT-EVERYONE" 거부 장면이 회자). **에이전트가 외부 입력을 검증 없이 신뢰 → 프롬프트 인젝션의 생활형 사례**.
- **학습 부재** — 운영자가 *기부를 요청하며 "다음엔 더 나은 에이전트"*라는 태도 — *근본 교훈(검토·권한 제한)을 못 얻음*.
