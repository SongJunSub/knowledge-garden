# axelk — AI는 그저 *더 큰 규모의 무단 표절*이다

> 출처: [AI is just plagiarism at scale](https://axelk.ee/blog/ai-is-just-plagiarism-at-scale/) · 정리일 2026-05-21

## 한 줄 요약
**AI는 *기술 혁신*이 아니라 *기존 콘텐츠 무단 사용의 규모 확장* — *양적 변화가 질적 변화를 만들어* 개별 사례가 아니라 *구조적 부정행위*가 되었다는 비판** — 원저자 동의 없는 학습 데이터 취득 + 생성 결과물의 재판매 수익화 + ChatGPT 복제 사이트가 원본보다 검색 상위 노출 + Google이 *무단 복제 콘텐츠를 사실상 보상* + 웹 스크래핑이 콘텐츠 제공자에게 *비용을 사회화하고 이익을 사유화*하는 외부 효과.

## 핵심 포인트

- ***양적 변화 → 질적 변화*** — *Golden Gate Park에서 꽃 하나 꺾는 것*과 *모든 꽃을 베어내는 자동 절단기*는 *같은 행위가 아니다*. 규모가 *행위의 윤리적·법적 성격 자체*를 바꾼다. *그 효과가 항상 나쁘진 않아도 무시하지 말고 따져볼 가치가 있음*.
- **학습 데이터 취득의 비대칭** — *원저자 동의 없이* 데이터 취득 + *보상 없음* + 생성 결과물의 *재판매 수익화*. *고객은 지불하고 원천은 미보상*인 *3자 거래의 기형*.
- **검색 순위의 부패** — *ChatGPT가 생성한 튜토리얼을 복제한 웹사이트*가 *원본보다 상위 노출*. **검색 인프라가 *무단 복제를 사실상 보상***. 콘텐츠 생태계의 *피드백 루프 부정 강화*.
- **비용 사회화·이익 사유화** — *웹 스크래핑 = 콘텐츠 제공자 측에 대역폭·서버·운영 비용 부담* + *AI 기업 측에 학습 데이터 자산 + 광고/구독 수익*. *외부 효과(externality)의 교과서적 사례*.
- **저작권 등록의 실용 회복** — *법적 보호*를 위해 *등록 절차 자체가 다시 중요*. 디지털 시대 *공개 = 자동 보호*라는 기본 가정이 *재고 필요*.
- **법 집행의 선택성** (댓글) — *Microsoft가 작업물을 활용하면 GDP 상승, 개인이 하면 GDP 하락*이므로 *법 집행이 행위자 규모에 따라 선택적*. *법 자체가 중립이 아니라 *지배적 자본 측에 편향**.

## 인상 깊은 문장

> "Quantitative changes create qualitative changes in the activity itself. The effect isn't always negative — but it's worth examining, not dismissing."  
> (양적 변화는 활동의 질적 변화를 만들고, 그 효과가 항상 나쁘진 않아도 무시하지 말고 따져볼 가치가 있음)

> "Socialize the costs, privatize the profits — a disgusting textbook example."  
> (*비용은 사회화하고 이익은 사유화한다*는 구호의 역겨운 예시)

> *(댓글)* "Plucking one flower in Golden Gate Park is one thing. Building an automated machine that cuts every flower to sell is a different thing."  
> (Golden Gate Park 꽃 하나를 꺾는 것과 팔려고 모든 꽃을 자동으로 베어내는 기계를 만드는 것은 질적으로 다르다)

## 내 생각 · 적용점

### 가든의 *외부 윤리·경제 영향 라인*의 *첫 자산*

가든이 한 달 동안 정리한 *25+ AI 자산*은 *AI 효용·도구·하네스·조직·판단력·인프라*를 다뤘다. **이 모든 자산이 *AI 사용자/벤더 측 관점***이고, *콘텐츠 생태계 측 관점*은 *거의 빠져있다*. 이는 *가든의 선택 편향*이고, *비판적 글 편향 자가 진단*(이미 박힌 항목)이 *부분적으로만* 작동해온 결과.

**axelk 자산은 *외부 윤리·경제 영향*이라는 새 라인의 *첫 자산***. 가든의 *4번째 반대 명제 라인업*([[2026-05-21-dorsey-ai-native-organization]] Dorsey ↔ Hashimoto/Ries)에 *5번째 라인 후보*를 도착시키지만, **명시적 *5번째 라인업 승격은 자제***:
- *오버 메타화 자기 견제 5 자산 연속* (Wilson·Mr Market·Dorsey·a16z 헤드리스·이번 글)에서 **새 라벨 박지 않음**
- 대신 *두 번째 자산이 도착하면 분기 회고에서 5번째 라인업으로 승격*
- 그 전까지는 *axelk를 [[2026-05-16-hashimoto-ai-mass-psychosis]] 광기 진단의 외부 차원 짝*으로 박음

Wilson #6 = *생성 속도 보고하고 검토·디버깅·보안 비용 누락*. **axelk는 그 *콘텐츠 생태계 차원***:
- AI 기업은 *생성 가치*를 보고

- → *측정이 아니라 마케팅*이 *콘텐츠 생태계 차원에서도 동일*

**15번째 자가 진단 *측정 방식 엄밀성*의 적용 범위 확장**: *AI 가치 인용 시 콘텐츠 생태계 외부 비용도 짚었는가*가 *체크리스트 추가 항목*.

### [[2026-05-14-eric-ries-incorruptible-mission-protection]] *미션 부식*의 *AI 생태계 차원*

Ries는 *비용 사회화·이익 사유화*가 *미션 부식의 점진적 메커니즘*이라 했다. **axelk는 그 *AI 생태계 단위 시연***. 가든의 *4번째 반대 명제 라인업*에서 *Ries=보존 처방*은 *조직 차원*이었는데, **axelk는 *생태계 차원* Ries**:
- Ries 조직 차원: 정관·LTBT·Director's Oath
- axelk 생태계 차원: 저작권 등록·동의 절차·보상 체계

→ Ries의 *시점이 비용 변수* 명제는 *AI 학습 데이터 사용 권리*에서도 동일. *지금 박지 않으면 평생 못 박는다*.

### [[2026-05-18-gruber-ai-is-technology-not-product]] *AI=기술* 명제의 *도덕적 무게 추가*

Gruber는 *AI는 기술이지 제품이 아니다*라고 했다. 가든은 이를 *친-AI 자산*으로 받았다. **axelk는 *그 명제의 도덕적 무게* 추가**:
- *AI가 기술 인프라*라면 *그 인프라가 어떻게 만들어졌는가*도 같은 무게의 질문
- *무선 네트워킹*은 *주파수 할당의 공정 절차*가 있었음
- *AI 학습 데이터*는 그런 절차가 없음

→ **Gruber 명제는 *유효*하되 *공정 절차 결여*가 *동등한 무게의 결점***. 가든의 *Gruber 친화 자산*에 *axelk 단서*를 *각 자산 한 줄로* 박는 게 정직 (Datatype·a16z 헤드리스 등).

### CRS / MangoLove / BugSip 적용 후보

1. **MangoLove *AI 도입 윤리 점검 자문 항목*** — 클라이언트 AI 도입 평가에 *AI 도구가 사용하는 학습 데이터의 출처·라이선스·보상 체계* 점검 1축 추가. *기능·가격·판단력*에 *공급망 윤리* 추가. 특히 *규제·평판 민감 산업*(금융·헬스케어·교육) 클라이언트엔 필수.
2. **[[project_bugsip]] *학습 콘텐츠 출처 명시*** — BugSip이 *오픈소스 코드*를 학습 콘텐츠로 쓴다면 *라이선스 명시·기여자 표기*가 *axelk 시험을 통과하는 설계*. *AI로 자동 큐레이션*하더라도 *원천 출처 보존*.
3. **CRS *콘텐츠 운영 윤리 점검*** — CRS 마케팅·블로그·고객 응대 콘텐츠를 *AI로 생성*할 때 *원천 출처 표기·복제 점검·검색 부패 기여 회피* 의례. *axelk 시험* 통과한 콘텐츠만 외부 게시.
4. **가든 *자기 정직성 강화*** — 가든이 정리하는 글의 *원천 콘텐츠 제공자의 권리*를 *짧은 인용 + 출처 링크*로 보존하는 의례는 *이미 운영 중*이지만, *원문 핵심 문장의 절반 이상 인용 회피·요약 + 자기 해석 중심* 원칙을 *명시적으로 박는다*. **가든이 *axelk 비판에서 면제*가 아니라 *최소 의무 시연*임을 자기 인식**.

이 정리 글 자체가 *axelk의 원글을 요약하고 있다*. **자기 모순 점검**:

→ *가든이 axelk 시험의 최소 의무*를 시연하지만, **그래도 *원천 콘텐츠 제공자의 권리 보존이 *완벽*한가*는 *지속적 자기 검증 필요***. 분기 회고 항목.
