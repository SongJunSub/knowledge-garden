## 한 줄 요약

**확산 언어 모델(Diffusion Language Model)은 토큰을 왼쪽에서 오른쪽으로 하나씩 이어 쓰는 기존 언어 모델과 달리, 빈칸으로 가득한 문장에서 시작해 여러 위치를 동시에 채워가며 반복 단계 수를 조절해 생성 속도와 품질의 균형을 맞춘다 — Mercury 같은 실제 모델은 일반 GPU에서 초당 1,000토큰 이상을 낸다.**

## 핵심 포인트

- **동시에 여러 위치를 채우는 구조** — 기존 언어 모델이 토큰을 하나씩 이어 쓰는 반면, 확산 언어 모델은 ***여러 위치를 동시에 채우며 반복 단계 수에 따라 생성 속도와 품질을 조절***한다.
- **학습은 마스킹·복원, 생성은 빈칸 채우기** — 기본적인 학습은 문장의 일부를 무작위로 가리고 복원하는 방식이며, 생성할 때는 ***빈칸으로 가득한 문장에서 시작해 점차 내용을 완성***한다.
- **블록 단위 생성 + 재수정 + 증류로 실용화** — 실제 모델은 ***블록 단위 생성, 이미 채운 토큰의 재수정, 생성 단계 수를 줄이는 증류***를 결합해 길이 제한·오류·속도 문제를 해결한다.
- **일반 GPU에서 초당 1,000토큰 이상(WebSearch 보강)** — Mercury는 일반 GPU에서 ***초당 1,000토큰 이상***을 생성하며, Inception Labs 측정 기준 Mercury Coder Mini는 H100에서 초당 1,109토큰을 냈다 — 전체 시퀀스를 동시에 처리하기 때문에 다음 토큰을 기다리지 않고 여러 토큰을 병렬로 확정할 수 있어서다.
- **복잡도에 따라 단계 수를 동적으로 조절(WebSearch 보강)** — 단순한 구조화된 출력은 8단계, 복잡한 추론은 16~20단계처럼 ***출력 복잡도에 따라 디노이징 단계 수를 동적으로 조절***해 속도와 품질을 자동으로 맞춘다.
