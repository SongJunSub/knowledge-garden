# FLUX 3 Image (Black Forest Labs)

## 한 줄 요약

**Black Forest Labs의 FLUX 3 Image는 "이 자리에 이게 들어가라"를 자연어가 아니라 0~1000 그리드의 사각형 좌표(bounding box)로 못박아, 포스터 글자 배치·콜라주·다인물 장면처럼 위치가 생명인 이미지에서 생성 결과의 불확실성을 구조적으로 줄인 모델이다. 수정도 같은 방식으로 작동해, 지정하지 않은 영역은 픽셀 단위로 그대로 보존된다.**

## 핵심 포인트

- **구도 지정 = 좌표, 설명 = 텍스트** — 각 영역을 `[top, left, bottom, right]`(0~1000 그리드) 사각형으로 먼저 찍고, 그 영역에 무엇이 들어갈지는 텍스트로 설명한 뒤 전체 장면을 하나의 프롬프트로 연결한다. ***"어디에"***와 ***"무엇을"***을 분리한 것이 핵심 설계다.
- **참조 이미지 최대 10장** — 256×256 ~ 16메가픽셀 범위의 참조 이미지를 최대 10장까지 받아 각 참조의 특정 요소를 지정한 좌표 영역에 배치할 수 있다. 여러 인물·사물을 한 장면에 합성하는 콜라주형 작업을 겨냥한 기능.
- **부분 수정 시 비수정 영역을 픽셀 단위로 고정** — 색상 변경·대상 교체·위치 이동 같은 여러 수정을 한 번에 지시해도, 지정하지 않은 배경과 요소는 ***그대로 유지***된다. 여러 차례 수정을 거쳐도 누적 열화 없이 다단계 편집이 가능하다고 밝힌다.
- **해상도** — 별도 업스케일 단계 없이 2K·4K를 직접 생성한다. 가격은 해상도에 비례해 768 사각형 $0.041, 1K(기본) $0.048, 1.5K $0.07, 2K $0.10, 4K $0.607 수준으로 보도됐고(출시 프로모션으로 10월 8일까지 50% 할인), 실패·모더레이션 차단된 요청은 과금되지 않는다고 한다.
- **공개 범위** — 2026년 10월 1일 BFL API로 먼저 공개됐고, 가중치 공개(오픈웨이트)는 "향후 몇 주 내"로 예고된 상태다 — 아직 오픈웨이트는 아니다.

## 내 생각 · 적용점

### 핵심 전이 — "세 번째 입력 모달리티"에서 "좌표 자체가 입력"으로, 같은 문제의 다른 해법

[[2026-09-09-chatgpt-images-2-5-release]]의 Sketch 기능은 "언어로 표현하기 힘든 공간적 의도(가구 배치·포즈)를 그림으로 그리게 하자"는 해법이었다. FLUX 3 Image는 같은 문제(텍스트만으로는 구도를 정확히 지시하기 어렵다)를 **그림이 아니라 숫자 좌표**로 푼다 — 사용자가 직접 그릴 필요 없이 사각형 네 개 숫자만 넘기면 되므로, API나 다른 도구가 자동으로 좌표를 생성해 FLUX에 넘기는 **파이프라인화**가 Sketch보다 쉽다. 반대로 Sketch는 사람이 직접 의도를 그려야 해 손맛이 필요하다. 두 모델이 "텍스트의 공간 표현력 부족"이라는 같은 진단에서 "자유로운 손그림"과 "엄격한 좌표"라는 양 극단으로 갈라진 것이 흥미롭다 — 억지로 우열을 매기지는 않는다. 용도가 다르다: 창작 과정에서 의도를 탐색할 땐 Sketch, 반복 생성을 자동화할 땐 좌표 기반이 유리하다.

## 호스피탈리티 / CRS 적용 포인트

**직접 적용은 멀다.** CRS 핵심 업무(요금·재고·정산)는 이미지 생성과 무관하다. 다만 [[2026-09-09-chatgpt-images-2-5-release]]에서 이미 남긴 "파트너 호텔 마케팅 이미지" 접점이 이번 모델로 한 단계 더 구체화된다 — 좌표 기반 배치는 **시즌 프로모션 배너처럼 "로고는 좌상단, 객실 사진은 중앙, 가격 문구는 하단"이 고정된 템플릿형 콜라주를 대량 생성**하는 데 손그림보다 적합할 수 있다(자동화 파이프라인에 좌표를 하드코딩하면 담당자 개입 없이 변형 생성 가능). 다만 이는 CRS 코어가 아닌 파트너 마케팅 지원의 가설적 적용이며, 검증된 사례는 없다.
