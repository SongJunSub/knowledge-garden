# Claude Fable은 끊임없이 적극적으로 움직인다 — 2줄 CSS 수정에 $12, 능력과 비용·위험의 양날 (경계 자산)

## 한 줄 요약

**Simon Willison이 *Fable 5로 CSS 버그를 디버깅*한 기록. Fable은 *스크린샷과 단순 프롬프트만으로 로컬 서버 실행·브라우저 조작·자동 스크린샷·JavaScript 삽입·CORS 서버 구축*까지 ***"끊임없이 적극적으로(relentlessly proactive)"*** 문제를 해결한다 — 창의적이지만, ***단순한 2줄 CSS 수정에 약 $12의 토큰***을 태웠다. 핵심 양면: *주도성·창의적 자동화는 인상적*이지만, *간단한 작업에 과한 탐색·검증으로 비효율적*이고, ***샌드박스 밖 실행은 프롬프트 인젝션·데이터 유출 위험을 크게 높인다.*****

## 핵심 포인트

- **끊임없는 주도성** — *브라우저 창 식별·Python CORS 서버·키보드 이벤트 시뮬레이션을 독자 구성*. *"사람에게 스크린샷 찍어달라 묻지 않으려고 $5어치 토큰을 태움"*.
- **비용 비효율** — *2줄 CSS에 ~$12*. **[[2026-06-08-fable-5-coding-benchmark-middling]] *타임아웃 최다·"토큰을 끝까지 쓰려는" 성향*의 질적 사례** — *50줄 패치를 30분 탐색으로 바꿈*.
- **샌드박스 보안** — *"코딩 에이전트를 샌드박스 밖에서 실행하는 건 항상 나쁜 생각"*. **[[2026-06-08-ai-agent-dn42-bankrupted-operator]] *$6,531 파산*과 같은 위험축** — 권한·환경 격리가 없으면 주도성이 곧 폭주.
- **"멈춰서 묻기"의 부재** — *상위 권한이 필요할 때 멈춰 묻는 대신 끝없이 우회로*. [[2026-05-09-agents-need-control-flow]] *정지 조건*의 결핍.

### 핵심 전이 — "주도성은 경계가 있을 때만 미덕"

[[2026-06-08-ai-agent-dn42-bankrupted-operator]]가 *권한 경계 부재의 파국*이면, 이 글은 *비용·판단 경계 부재의 낭비*다. 둘 다 결론은 같다: ***끊임없는 주도성 + 경계(비용 상한·정지 조건·검토 게이트) = 미덕, 경계 없으면 폭주***. 댓글의 *"검토 맡기라 지시하면 토큰 적게 유용"*이 핵심 — [[2026-06-08-designing-loops-with-fable-5]] *명확한 평가 기준·정지 조건*이 빠진 루프는 *강력할수록 비쌈*.

### 핵심 전이 — "인간 학습 기회의 상실"

HN의 날카로운 지적: *"에이전트가 $12 쓰고 고치게 두면, 나는 추상화를 개선할 기회를 버린다"*. [[2026-06-08-human-attention-human-effort]] *노력·검토는 사람 몫*·[[2026-06-08-30x-ai-engineer-with-taste]] *판단·분별력*과 정합 — **위임이 "이해를 건너뛰는" 게 되면, 길이·복잡도엔 이득이어도 분별·판단은 퇴화**. [[2026-05-29-orchestration-tax]] *"우편함까지 콜벳"*은 그 비효율의 밈.

### 작업 규모에 맞는 도구 — "종이 삽"의 반대편

*"CSS 2줄엔 Fable 쓰지 말 것, 복잡·오래 걸리는 작업에만"* — [[2026-06-08-static-types-and-the-shovel]] *"도구는 용도"*의 적용. *Fable의 주도성은 까다로운 디버깅·복잡한 조율에선 강력*하나 *단순 작업엔 과잉*. 도구 선택 자체가 판단.
