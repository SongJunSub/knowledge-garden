# OpenAI Images 2.6 공개 - GIF 생성, SVG 출력과 더 빠른 이미지 편집

> 출처: 원문 미확인 (GeekNews 경유, id=36635) · 정리일 2026-11-06

> **출처 한계**: OpenAI의 공식 "Images 2.6" 발표를 1차 자료로 확인하지 못했다. WebSearch에서 확인되는 가장 가까운 공식 제품은 2026년 9월의 **Images 2.5**(참조 사진 보존, 반복 편집 안정성, Images 2.0 대비 지연시간 최대 50% 단축, Sketch 입력 방식 추가)이며, 이는 [[2026-09-09-chatgpt-images-2-5-release]]에서 이미 정리했다. "2.6"이라는 이름은 제3자 집계 사이트 openart.ai의 "GPT Image 2.6"("곧 출시" 라벨) 페이지에서만 확인됐다 — **버전 번호·공개 시점 모두 OpenAI 1차 발표로 대조하지 못한 상태**로, 번호 체계나 공개 여부 자체가 부정확할 가능성을 열어둔다.

## 한 줄 요약

**Slack 발췌에 따르면 OpenAI가 ChatGPT·Codex·API에 Images 2.6을 도입해 애니메이션 GIF 생성, 벡터 기반 SVG 출력, API 수정 위치 지정 마크업을 추가하고 생성 속도를 기존보다 50% 높였다고 전한다. Images 2.5(참조 보존·반복 편집 안정성에 집중)의 다음 단계로 "입력·출력 형식의 다양화"에 초점을 옮긴 것으로 보이지만, 공개 자체를 1차 자료로 확인하지 못했다.**

## 핵심 포인트 (Slack 발췌 기준, 일부 미확인)

- **애니메이션 GIF 생성**: 브랜드 마스코트, 제품, 소셜미디어 반응 이미지와 밈, 간단한 스케치도 움직이는 캐릭터로 바꿀 수 있다는 주장.
- **API용 SVG 출력**: 수정 위치를 지정하는 이미지 마크업과 SVG 출력을 API에 추가 — SVG는 참조 이미지를 만든 뒤 이를 바탕으로 벡터 문서를 생성하는 방식이라는 설명.
- **속도 개선**: 생성 속도가 기존보다 50% 빨라졌다는 주장(기존 대비 기준이 Images 2.5인지 2.0인지는 Slack 발췌에서 불명확).
- **참고 — Images 2.5와의 계열**: [[2026-09-09-chatgpt-images-2-5-release]]는 참조 사진 보존·부분 편집 안정성·Sketch 입력을 핵심으로 다뤘다. 이번 "2.6" 주장이 맞다면, **"입력 방식 확장"(2.5의 Sketch) → "출력 형식 확장"(2.6의 GIF·SVG)으로 자연스럽게 이어지는 로드맵**으로 읽힌다.
- **third-party 단서**: openart.ai의 "GPT Image 2.6" 모델 페이지는 사진을 짧은 루프 GIF로 바꾸는 기능과 "GIF로 빠르게 내보내기"를 설명에 포함하고 있어, GIF 관련 주장과는 방향이 일치한다("곧 출시" 라벨이라 공개 시점 확정은 아님).
