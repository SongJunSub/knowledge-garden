# 태스크 이코노미 - 데이터가 만드는 다음 1조 달러 시장 (Everett Randle) — 모델 개선의 단위가 토큰에서 태스크로 옮겨갔다

> 출처: [The Task Economy](https://x.com/EverettRandle/status/2074527860510085498) (Everett Randle · X 스레드 · GeekNews GN⁺ 요약) · 정리일 2026-07-20

## 한 줄 요약

**추론의 단위가 '토큰'이라면, 모델 개선의 단위는 '태스크'다 — 강화학습 관점에서 태스크는 모델이 연습하는 단위(초기 상태 + 행동 환경 + 보상 신호/검증기)이고, 여러 태스크의 점수가 학습 신호로 종합돼 모델을 조정한다. 인터넷에서 새로 배울 데이터가 소진되고 단순·범용 능력이 포화되면서, 이제 병목은 '실제 환경에서 전문가의 암묵지를 가르치는 고품질 데이터'다. 그래서 OpenAI·Anthropic의 데이터 지출이 연 10배씩 늘고 Mercor ARR이 4개월 만에 $1B→$2B로 뛰는데, 토큰 같은 표준 가치 단위가 없고 랩의 비밀주의 때문에 이 '태스크 경제'가 잘 안 보인다. 법률·의료·금융·SW·과학이 각각 전문가 데이터셋·도메인 평가·RL 환경을 따로 필요로 하며, 데이터 인프라를 잡는 조직이 프런티어 능력과 시장을 가져간다는 것이 요지다.**

## 핵심 포인트

- **태스크의 정의(RL 관점)** — 모델이 *연습하는 단위*: ①초기 상태와 행동 환경 제공, ②모델의 행동을 **보상 신호/검증기로 채점**, ③여러 태스크의 점수를 학습 신호로 종합해 모델 조정.
- **토큰 vs 태스크** — **토큰**=추론·사용의 단위(공개 추적 가능, "AI 확장을 이해하는 공통 언어"). **태스크**=모델 개선의 단위(비밀주의 강함, 고품질 데이터로 점진적 능력 향상을 측정).
- **왜 지금 병목인가** — *"인터넷에서 새롭게 학습할 데이터가 소진"* + *"단순·범용 능력이 점차 포화"* → **실제 환경에서 전문가의 암묵지를 가르치는 고품질 데이터**가 발전의 병목으로 부상.
- **시장 규모 신호** — OpenAI·Anthropic 데이터 지출 **연 10배** 증가. **Mercor ARR $1B(2월)→$2B(4개월 후)**. 주요 AI 기업들이 **개별 태스크 카테고리에 $100M+** 지출.
- **왜 안 보이나** — ①지출이 프런티어 랩에 집중(모델 개선 전략 비공개), ②**토큰처럼 가치를 추상화하는 공통 단위 부재**("태스크용 OpenRouter" 없음). Mercor 분기 데이터가 유일한 간접 지표.
- **도메인별 별도 구축** — *"법률·의료·금융·SW·과학은 각각 전문가가 만든 데이터셋, 분야별 평가 체계, RL 환경이 필요."* 법률 예: 계약 검토·논거 작성 프롬프트 + 법률 데이터룸 + 기업 변호사 에이전트 평가표의 결합.
- **시사점** — 데이터가 경쟁 우위. *"경제적으로 유용한 업무 전반에서 데이터 인프라 경쟁"* 전망. 데이터 인프라를 잡는 조직이 **프런티어 능력의 지속 개선 + 시장 점유**를 확보. 산업이 토큰과 함께 **"태스크 규모"도 성장 지표로 추적**할 것.

## 인상 깊은 문장

## 내 생각 · 적용점

### 핵심 전이 1 — 어제 "데이터가 유일한 해자"의 공급 측 짝이다

어제 정리한 [[2026-07-20-data-is-your-only-moat]]가 **응용 측**(앱이 사용 중 쌓는 고객 데이터=해자)을 말했다면, 이 글은 **공급 측**(프런티어 모델을 훈련하는 태스크/RL 데이터=병목)을 말한다. 둘은 같은 명제("데이터가 희소 자산")를 **다른 층**에서 반복한다 — 그런데 정확히 이어진다: **앱이 쌓는 "수락/거절 피드백"이 곧 태스크(초기 상태+행동+보상)다.** 즉 어제 글의 "데이터 해자=내장된 평가 루프"는 이 글의 "태스크"와 **같은 것의 두 이름**이다. 앱이 데이터 해자를 쌓는 행위가 곧 태스크 경제의 원료를 생산하는 행위다.

### 핵심 전이 2 — 모델의 병목이 인간의 병목과 같아졌다: 전문가의 암묵지

이 글의 가장 깊은 통찰은 *"인터넷 데이터가 소진되고, 이제 필요한 건 전문가의 암묵지"*라는 것이다. 이건 이번 몇 주 "판단이 병목" 축과 **정확히 만난다** — [[2026-07-17-wes-mckinney-ai-arrow-future-of-software]]가 *"AI는 판단을 만들어주지 않는다"*고 했는데, 이 글은 **그 판단(전문가 암묵지)이 이제 모델 훈련의 병목이기도** 하다고 말한다. 즉 **인간에게 희소한 것(판단·전문성)이 모델에게도 희소하다.** 범용 능력은 상품화됐고([[2026-07-18-state-of-open-source-ai-2026-mozilla]] 패리티), 남은 프론티어는 도메인 전문가의 암묵지를 태스크로 인코딩하는 것 — 이건 [[2026-07-20-ai-wrapper-dead-verticalization]]의 "도메인·워크플로 소유"가 **랩이 사려는 자산**이기도 하다는 뜻이다.

### 핵심 전이 3 — 토큰 경제 다음의 계측 단위, 그리고 "표준 단위 부재"의 의미

[[2026-07-13-how-an-ai-token-travels-through-a-data-center]]가 "토큰=추론 비용(COGS)"을 원리로 풀었다면, 이 글은 **토큰 옆에 '태스크'라는 훈련 축**을 추가한다. 흥미로운 건 *"태스크용 OpenRouter가 없다"* — 즉 **표준 가치 단위가 없어서 시장이 불투명**하다는 지적이다. 이건 [[2026-07-18-state-of-open-source-ai-2026-mozilla]]가 "쓰기 권한 표준이 없다"고 한 것과 같은 형태의 **표준 부재 = 계측 불가 = 통제·경쟁 구조 불투명**이다. 표준 단위가 생기는 순간(누가 태스크의 OpenRouter를 만드느냐) 이 시장이 드러난다.

### 핵심 전이 4 — 정직한 경계: VC 논지의 "1조 달러"는 방향이지 크기가 아니다

"다음 1조 달러 시장"은 VC의 headline이다. 견고한 부분과 걸러야 할 부분을 나누면 — **견고**: 인터넷 데이터 소진 + 범용 포화 → 도메인 암묵지가 병목(이건 여러 소스가 지지), 라벨링·RL 데이터 지출 급증(Mercor·연 10배는 실측 신호). **걸러야 할 것**: "1조 달러" 크기, "태스크 경제"가 완전히 새 카테고리라는 프레이밍(기존 데이터 라벨링·RLHF의 확장이기도), VC가 자기 책을 파는 톤. **방향(데이터/암묵지가 훈련 병목)은 취하되, 규모·시점은 유보.**

## 호스피탈리티 / CRS 적용 포인트

- **온다의 운영 데이터는 '태스크 경제'의 원료가 될 수 있다.** 예약·정산·예외처리에 담긴 호스피탈리티 도메인 암묵지는 인터넷에 없는, 랩이 원하는 종류의 데이터다 — 이건 [[2026-07-20-data-is-your-only-moat]]의 해자를 **두 배로 값지게** 만든다(앱 해자 + 태스크 원료).
- **그러나 원료를 넘기면 해자가 사라진다.** 이 데이터를 랩에 팔거나 학습에 노출하면 "데이터가 유일한 해자"를 스스로 지운다 — 프롬프트 위생(§5)·데이터 거버넌스로 **소유는 유지, 노출은 통제**.
- **내부 개선 루프로는 유용.** 온다 자체 기능 개선을 위한 태스크(수락/거절·예외 처리를 보상 신호로)는 내부에서 돌리되, 결정적 경로(요금·정산)는 학습이 아니라 결정적 코드로(§7).
