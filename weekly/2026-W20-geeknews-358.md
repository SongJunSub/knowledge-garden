## 주간 메타 가설 — 가든의 시각

**1. *공급자 종속에서 *분리·교차·로컬*로* 가 주간의 단일 축**.
주간 인기 글을 한 줄로 묶으면 *모델·도구·플랫폼 한 곳에 묶이지 마라*. 분리의 4가지 변형:
- **로컬 분리**: ds4·Rapid-MLX·M4 로컬 모델·*로컬 AI 표준화*
- **공급자 교차**: [무신사 query-engineer Claude+Codex 8 리뷰](../ai/2026-05-18-musinsa-query-engineer-harness.md)
- **호스팅 탈출**: GitHub 침몰·AWS 비판·*git-sync = GitHub 이탈 준비*
- **디자인 시스템 탈출**: Open Design

**모두 같은 모양** — *한 공급자가 내 *주의·시간·결정*을 결정하는 구조 거부*. [Ascetic Computing](../engineering/2026-05-17-ascetic-computing-ratfactor.md)이 *개인 라이프스타일 차원*에서 본 것을 *주간 흐름이 시장 차원*에서 본다. **두 시각이 *같은 한 줄*에서 만난다 — 자기 결정권 회복**.

**2. *모델은 표준화 자원, 차별점은 하네스와 조직***.
주간이 던진 정확한 한 줄. [무신사 *Agent = Model + Harness*](../ai/2026-05-18-musinsa-query-engineer-harness.md)가 *공식*이라면, GN#358의 **#29486 *AI 분야 다음 해자 = 조직***이 *Conway의 Law 차원* 정리. 두 글이 *같은 명제의 두 층위* — 하네스(개인·팀 차원) + 조직(회사 차원). **이걸 가든의 *제목 한 줄*로 박을 수 있다 — *모델이 표준화될수록 차별점은 위로 올라간다(하네스 → 조직 → 거버넌스)***.

**3. *주간이 가든의 약한 영역을 정확히 가리킨다 — 로컬 AI***.
가든은 [Rapid-MLX] 한 글만 가지고 있고, *로컬 AI 표준화 가설*은 정리하지 않음. 이번 주 메인 특집이 *그 공백을 정확히* 짚는다. 가든의 다음 정리 후보:
- **#29369 *로컬 AI가 표준이 되어야 함***을 가든의 *로컬 AI 메타 가설* 자리에 박기
- *비싼 모델 vs 로컬 모델 하이브리드 워크플로*가 [Anthropic LTBT 거버넌스](../career/2026-05-14-eric-ries-incorruptible-mission-protection.md)의 *시장적 답*이라는 가설

**4. *가든 운영의 *Ascetic 모드 실험*에 대한 외부 검증***.
어제 [Ascetic Computing](../engineering/2026-05-17-ascetic-computing-ratfactor.md) 정리에서 *주 1~3개만 선택*하는 *Ascetic 모드*를 가설로 박았다. 이번 주간 글이 *그 가설의 직접 검증* — *주간 인기 글 *상당수가 가든이 이미 정리한 글*과 일치*한다면, **선택적 정리가 흐름을 놓치는 게 아니라 *정확히 따라잡는다***. 가설의 *외부 확증*. 다만 *남은 새 글들*(로컬 AI 라인 + #29486 조직 해자 + #29399 유지보수 비용 + #29486)이 *공백*을 가리키므로, *완전히 자동 흡수하지 않는 동시에 *공백을 인식해서 선택적으로 메우는* 의례*가 필요. 그게 *주간 큐레이션 정리의 가치*다 — 매일 글이 아니라 *주간 메타 시각*.
