# 북한의 가짜 채용 면접이 Binance 63억 달러 탈취로 이어졌다(GeekNews)

> 출처: [북한의 가짜 채용 면접이 Binance의 63억 달러 탈취로 이어짐](https://news.hada.io/topic?id=36596) (GeekNews) · 정리일 2026-11-05

> **출처 한계**: news.hada.io 차단으로 원문 열람 불가, Slack 발췌는 "침해된 컴퓨터와 내부…"에서 말미 절단. WebSearch로 교차확인한 결과 Binance 해킹 규모는 매체마다 **$6.3B(가장 흔함) ~ $6.36B(TRM Labs)**로 표기되며, Slack이 전한 "63억 달러"와 대략 일치한다. 다만 **"가짜 채용 면접 → pyenv 구성요소 악성 교체"라는 구체적 공격 벡터는 WebSearch로 독립 교차확인하지 못했다** — 찾은 보도들은 "DevOps 엔지니어 노트북 침해"(Binance 공동대표 발언), "일반적으로 TraderTraitor가 가짜 채용으로 접근한다"는 패턴만 확인됐고, pyenv라는 구체적 메커니즘은 이 Slack 발췌가 유일 출처다.

## 한 줄 요약
**이 글은 [[2026-10-31-binance-hack-8-5-trillion-won]]에서 "귀속 미확정"으로 남겼던 같은 Binance 해킹(약 6.3~6.36억 달러, 10개 지갑, 20분 내 유출)의 최초 진입점을 메운다 — 공격자는 가짜 채용 면접 과제로 전달한 코드 저장소를 통해 정상 pyenv 구성요소를 악성 버전으로 교체했고, 단말 보안 도구는 이를 즉시 탐지하지 못했다.**

## 핵심 포인트
- **면접 과제 ZIP/repo가 최초 침투 경로** — 채용 과제로 전달된 코드 저장소에 ***정상 pyenv 구성요소를 악성 버전으로 교체***하는 수법이 포함됐다. 이는 [[2026-07-24-fake-interview-git-hook-malware]]의 ".git/hooks/pre-commit에 페이로드를 심는" 방식과 사실상 같은 패밀리 — 전달 매개체(패키지 매니저 구성요소 vs git hook)만 다르다.
- **단말 보안 도구가 즉시 탐지 못함** — 알려진 도구의 알려진 설치 경로를 흉내 낸 변조라 EDR/안티바이러스 시그니처 기반 탐지를 우회했을 가능성.
- **단일 단말 침해 → 내부 시스템 전체 침해로 확산** — Binance 공동대표도 별도로 "침해된 DevOps 엔지니어 노트북이 서비스 컨테이너 접근권을 줬다"고 밝힌 바 있어(WebSearch 확인), 단말 하나의 침해가 왜 치명적인지 보여주는 또 다른 사례.
- **공급망 공격 + 사회공학 + 내부 AI 도구 침해의 결합** — Slack 발췌는 이를 "단순 피싱이 아닌 다단계 공격"으로 규정한다.
- 이 사건의 전체 피해 규모·자금 이동 속도(20분)·EIP-7702 악용 등은 이미 [[2026-10-31-binance-hack-8-5-trillion-won]]에서 다뤘으므로 이 노트는 **진입점(entry vector)만 추가 정리**한다.

## 내 생각 · 적용점
### 핵심 전이 1 — "면접 과제"는 이제 하나의 정형화된 공급망 공격 입구다
[[2026-07-24-fake-interview-git-hook-malware]], [[2026-06-08-linkedin-job-offer-backdoor]]에 이어 세 번째로 쌓이는 "가짜 채용/면접 과제" 공격 사례다. 패턴이 반복된다는 것 자체가 신호다 — ***채용 과제로 받은 코드는 실행 전 반드시 격리 환경에서 검사해야 하는 공급망 침해 경로***로 굳어졌다.

### 핵심 전이 2 — 미확정 정보를 "잠정 정보"로 다루는 태도가 보상받았다
[[2026-10-31-binance-hack-8-5-trillion-won]]에서 "귀속은 미확정"이라 신중하게 남겨둔 것이, 이번 후속 보도로 일부 채워졌다. **단정하지 않고 갭을 명시해 두면, 후속 정보가 왔을 때 노트를 깨끗하게 보강할 수 있다** — 정직한 불확실성 표기의 실질적 이득.

## 호스피탈리티 / CRS 적용 포인트
**부분적으로 적용 가능.** 온다는 블록체인 지갑은 다루지 않지만, **"채용 과정(과제·레퍼런스 체크)이 공급망 침투 경로가 될 수 있다"**는 원칙은 외주 개발자·계약직에게 코드 접근권을 줄 때 온보딩 격리 절차(샌드박스 실행, 권한 최소화)로 직접 전이 가능하다.
