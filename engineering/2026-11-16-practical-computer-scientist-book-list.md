# 실전파 컴퓨터 과학자를 위한 도서 목록 — 유행 대신 기초

> 출처: [실전파 컴퓨터 과학자를 위한 도서 목록](https://news.hada.io/topic?id=37232) (GeekNews · hada 차단, 원 블로그 특정 실패) · 정리일 2026-11-16

## 한 줄 요약
**프레임워크 유행이 아니라 언어·OS·네트워크·알고리듬·계산이론 같은 반감기 긴 지식에 돈과 시간을 쓰라는 2025년판 추천 목록.**

## 핵심 포인트
- 일반적인 "좋은 프로그래머 되는 법" 추천서(클린 코드류) 대신, ***언어·운영체제·네트워크·알고리듬·계산 이론을 깊이 익히는 책***에 초점을 맞춘 목록이라고 Slack 발췌가 소개.
- 입문 목록은 C/C++와 Rust 중심 — 직접 개발 용도보다는 ***주요 운영체제의 네이티브 API를 표현하는 공통 언어***라는 이유로 선택됐다고 함.
- WebSearch로 교차확인한 일반적 추천 패턴: C는 K&R *The C Programming Language*, Rust는 공식 "The Rust Book", 시스템 전반은 *Operating Systems: Three Easy Pieces*(OSTEP)·*Designing Data-Intensive Applications*가 널리 반복 추천됨 — 이 글이 정확히 같은 책을 꼽았는지는 **원문을 못 찾아 1:1 대조 불가**.
- 본격 목록은 시스템 프로그래밍과 CS 기초 전반, 고급 목록은 계산 복잡도·타입·함수형 자료구조·람다 계산까지 다룬다고 Slack 발췌가 전함(이 부분은 발췌 자체가 말줄임으로 끝나 전체 목록 미확인).

## 인상 깊은 문장
> "코드 작성 관행을 다루는 일반적인 프로그래머 추천서 대신 언어, 운영체제, 네트워크, 알고리듬, 계산 이론을 깊이 익히는 책에 초점을 맞춤" (Slack 발췌, hada 원문 비대조)

## 댓글
hada 접속 차단으로 원문 댓글 수·논조 확인 불가. 원 블로그 저자·게시 시점도 WebSearch로 특정하지 못해 **출처 신뢰도가 이번 배치 중 낮은 편**이다 — 실제로는 흔한 "추천 도서 목록" 장르 글 다수와 겹치는 내용이라 어느 특정 글인지 변별이 어려웠다. 목록 자체의 정확성(책 제목·판본)은 원문 대조 없이는 보증할 수 없다는 점을 명시해둔다.

## 내 생각 · 적용점
"프레임워크는 5년이면 바뀌지만 OS·네트워크·알고리듬은 20년을 간다"는 생각 자체는 가든의 반복 테마(matklad의 아키텍처 학습 글, Google Rust 스타일가이드)와 결이 같다. 다만 이 글은 특정 책 목록이라는 ***레퍼런스*** 성격이 강해 지금 당장 적용점을 억지로 뽑기보다, "팀 내 추천도서" 목록을 만들 때 참고 후보로만 저장해두는 게 정직한 처리.

## 호스피탈리티 / CRS 적용 포인트
직접 적용은 멀다. 다만 CRS/PMS 백엔드 엔지니어 온보딩 자료에 "프레임워크 문서"뿐 아니라 "네트워크·OS 기초" 자료를 끼워 넣을 가치가 있다는 원칙 정도만 참고할 수 있다.
